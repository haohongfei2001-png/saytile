## 实际修改

在已有文字生成后，用同一识别器在当前真实音频条件下并行核对上一轮 token 提案，逐位置拒绝不符的词，然后继续正常解码。录音头800毫秒、短于3秒的预览、窗口边界和整段最终解码沿用原路径。没有把未经核验的前文强制注入解码结果。

修复中英混说的 Smartphone → smart phone 间距改写导致后续中文长期等候的问题。新的发布条件需要两个增长的候选一致，保护数字、否定词和原来的所有权检查。预览稳定可外部派发范围仍为零，最终文字、用户修改和剪贴板使用原有保护。

## 修复与未解决的根因

Qwen 对增长音频完成了两次相同的真实解码，但 Worker 的去重会吞掉第二次观察；发布器恰好要求两个独立观察确认已读区域中的有限修订，因而可能一直保留旧文字。现在每次真实解码都能到达发布器，以增长 PCM 帧数证明它是新观察；相同/倒退帧不能虚假确认，已显示的相同文字也不会重复落盘。没有新建解码任务，没有伪造字词，没有放宽数字、否定、用户编辑或外部投递保护。

该缺陷在既有 fixture 中确定复现并修复。但是此前 70 条真实轨迹的重建没有量出更早的非最终发布，本次原生测量也没有形成整体提速证据。不能把这个局部正确性修复说成已根治停显。

现有长句停显仍包含单个 Qwen worker 的实际解码/标量定稿等待，以及相邻候选反复变化后未满足文字发布证据的等待。原音独立保存。38.8 秒连续夹具的漏词已存在于原始模型终稿，非窗口吞掉已识别文字；原始终稿、SQLite 与最终窗口一致，并不意味着模型没有漏字。此次未改模型参数、权重、录音、VAD、标量终稿、UI、数据库或外部输入逻辑。

## 停说等待实验：因准确率退化拒绝

现有 Qwen VAD 75 帧静音判定（20 ms/帧）约 1.5 秒。仅在独立实验树测试 50 / 60 帧，产品仍为 75。

- 440 条 VAD 对照：75→50 的分段数 448→462、15 条上下文改变；75→60 为 448→455、8 条上下文改变。保留 PCM 的每段源区间逐字节校验，不把字节守恒当成语义正确。
- 50 帧的 4 条优先 ASR 样本总 CER 恰好持平，但金额句 `现金` 变为 `现今`，不可接受。
- 60 帧复验同一金额句，仍从正确的 `现金` 变为 `现今`，再次拒绝。
- 两种方案都没有进入产品。停止剩余大批识别和继续微调阈值，不用更多有利样本稀释已经观察到的语义退化。

[原始失败证据、输入、补丁及构建来源](endpoint/)。现有 1.1 秒停顿测试已加强：先断言第一段确实进入说话状态，再验证暂停后仍为同段；此前测试的第一段单频音未触发 VAD，不能作为缩短阈值的充分依据。

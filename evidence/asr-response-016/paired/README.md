## 指标口径与文件

- `baseline/`、`candidate/`：各 15+3 原始收据和原生截图；`panels.json`、`extended.json`为原评分器结果，`words-panels.json`独立统计参考词类型的首次进展，不能称为 WER。
- `paired-revisions.json`、`paired-live-panels.json`：同输入的逐片段对比；文字回改不自动等于识别错误，新增文字也不自动等于准确率改善。
- `stop-*.json`：复用既有声学阈值估计停说位置，区分 raw final、最终文字持续显示、全文件处理结束。旧 `after_last_signal` 使用 whole-file settled，尾静音会放大它，不能拿 EOF 完成冒充用户停说响应。旧 probe 未记录精确 VAD endpoint 或 SQLite commit 时刻，相应字段为 NOT_RECORDED。
- `inputs/`、`configuration/`：原顺序、参考文本、音频 SHA、来源许可与模型版本。38.8 秒是五段合法公开语音拼接，不是自然单人长谈。34.58 秒尾静音样本没有完整参考，不计算 CER。
- `harness/`：来自候选源码 SHA 的实际评分/运行脚本与原归一化实现。`preparation/run-clean-interleaved.py`是实际任务编排器，其原始绝对路径为执行记录；重放时须提供对应源码 App、公开 WAV 和按 SHA 核验的模型，不包含可执行包或权重。
- `identities.json`、签名日志、`environment.jsonl`、`host-pressure.jsonl`和 `COPY-SOURCES.json`绑定来源与机器状态。主机未被强制清空后台应用；没有并行本任务编译或第二个识别器。
- CPU 和内存原始采样在相邻 `../resource/`。CPU 降低尚未证明；阶段内存差异尚未完全归因。

真实内置麦克风、用户口音、8 GB 真机、GPU/ANE 功耗和电池仍为 NOT_RUN。未访问私人录音、私人数据库、Keychain，未调用云 API，未安装或发布本候选。

`SHA256SUMS.txt`覆盖本目录除校验表自身外的全部文件。

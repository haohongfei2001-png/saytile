# Qwen 停止响应端点实验：50 / 60 均拒绝

**REJECTED / NOT ADOPTED。产品保留 75 个 20 ms 静音帧（1.5 秒）。** 两次隔离实验分别尝试 50 帧（1.0 秒）与 60 帧（1.2 秒），目标是缩短用户停止说话后的确认等待。发现相同的金融词语义退化后停止，不继续试 65 / 70，不进行全量模型识别或原速验收。

## 控制变量及来源

主机基线 `d0b2d87320fd4145fbaea756690066bca3718bab`。两份补丁只改变 Qwen 0.6B 本地路由的静音端点，并把所选模型身份冻结在录音开始时的 Snapshot 中；其他本地模型仍为 75 帧，云端仍为 100 帧，采集、VAD 算法、段长、预录、推理及评分参数不变。实验没有进入产品分支、安装版或用户资料。

所有实际 ASR 调用使用同一个已签名 484 App 的原始 `SaytileModelWorker`，SHA-256 为 `9b21b863a3b5bad11d4d36ee33b8204c0648da9409a977fd64d1c756cea2340e`。权重为 `aufklarer/Qwen3-ASR-0.6B-MLX-4bit` 的固定修订 `bc441bd1e4295c1f42d9879f056049a925b6e013`。`runtime-identity.json` 与 `qwen-small-manifest.json` 保留完整来源和文件校验值。每个 WAV 在进入测试前核对 SHA-256，模型加载使用产品完整性校验。只使用公开许可音频、临时 SQLite 和独立资料目录；一次一个 ASR，不打开麦克风，不访问付费 API。

## 已执行与结果

| 检查 | 75 基线 | 50 实验 | 60 实验 |
| --- | ---: | ---: | ---: |
| 全部 440 条真实 VAD / PCM 分段 | 448 段 | 462 段；15 条上下文变化 | 455 段；8 条上下文变化 |
| 实际模型产品链路样本数 | 4 | 相同 4 条 | 其中金融样本 1 条 |
| 4 条 CER 编辑错误 / 参考字符 | 5 / 204 | 5 / 204 | 未运行 4 条全集 |
| 金融样本编辑错误 / 参考字符 | 0 / 21 | 1 / 21 | 1 / 21 |
| 端点决策 | 保留 | 拒绝 | 拒绝 |

金融样本 `aishell1-test-72ae32cd8dfe9da8` 的参考及 75 帧输出保留“**一零万元现金埋地底**”。50 与 60 帧均切在金额之后，并输出“**一零万元。现今埋地底**”。原音未丢失、两段均完成，但丢掉跨停顿上下文后，“现金”变为“现今”。这是真实词义退化；数字仍相同，不能仅检查数字字符来判定安全。

50 帧另一个样本把“他们”修正为“它们”，减少一字错误，因此四条总 CER 恰好相同；不以这一抵消掩盖金融词退化。其余两条完整归档相同。`fleurs-c8c817e80216ce40` 多出一个失败子段，完整文本仍与正确基线相同，未把空子段失败计作漏句。

`vad75-vs50-440.jsonl` / `vad75-vs60-440.jsonl` 包含各 WAV 与 PCM 摘要、实际保留区间和分段关系。保留区间逐字节相等只证明保存的 PCM 没被改写，不等于更短阈值没有遗漏弱声尾部；未保留区间也可能是待命静音，不能全部当作丢字。VAD 统计独立于 ASR 准确率。

## 局限与未运行项

- ASR 是相同公开音频的加速完整产品链路对照，验证词义和归档；不是原速延迟或现场麦克风验收。
- 50 帧仅运行优先 4 条，60 帧仅运行金融关键样本。其余受影响样本、440 条全部 ASR、原速 15 条及静音尾延迟均为 **NOT_RUN**，因已出现不可接受的关键词退化而主动停止。
- 未证明任何停止延迟、CPU、内存或功耗收益，也未解决高负载下独立 scalar EOS 的长尾。Mac 保持合盖，个人自然讲话未测。
- 两组代码及构建输出均保留来源摘要；本目录不含权重、私人音频、可执行文件或安装包。

## 复核入口

- `experiment50.patch`、`experiment60.patch`：相对主机基线的精确实验差异。
- `provenance50.json`、`provenance60.json`、`build*.log`：编译来源、Cohort / Kit 哈希及执行状态。75 的 Cohort 复用根任务在同基线构建的 debug Kit；50 / 60 使用独立工作树构建。60 增量复用 50 的编译缓存，但生成独立、哈希不同的 Cohort。路径为当次原始环境记录。
- `priority4-*.jsonl`、`finance-candidate60.jsonl`：原始完整归档、模型及段状态；对应 comparison 文件保留参考原文及逐项编辑数。
- `full440-manifest.json`：160 FLEURS、80 ASCEND 中文、80 ASCEND 混说、100 AISHELL-1、20 降音量或噪声派生，合计 440 条。
- `vad*-build.json`、`vad-driver*.swift`、`vad-combined-source*.swift`、`build-vad.sh`：真实产品 VoiceSegmenter 提取、C WebRTC 绑定与全部 VAD 数据生成来源。
- `MandarinCohort.swift` 与 `build50.sh` / `build60.sh`：实际完整链路的构建及调用方法。原始脚本保留当时绝对路径，重放时需映射到新隔离目录和同一公开 WAV / 权重；不得运行在用户档案目录。
- 在包含现有评分器的基线仓库内执行 `python3 <本目录>/recompute.py --repo <仓库路径>`，可从原始输出复算已执行的 CER 对照；不运行识别模型。

所有文件由 `SHA256SUMS.txt` 绑定。两次拒绝结论不构成对未测其他端点的性能结论。

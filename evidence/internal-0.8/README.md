# Saytile 内测 0.8 机器验收

产品源码 `f18c2b5f2ad15aec7f66cc34fa79ad671936a532`。所有录音和文字验证均使用隔离资料，没有接触个人语音档案。这里的 AX 记录来自专用虚构输入框，不含真实对话。

| 场景 | 实测 |
| --- | --- |
| 空转写、只有手写备注、只有临时文字、预览后删除正文 | 旧版会清除四份原音。修复后即使直接提交这批 ID 也保留四份原音文件，只清掉有真正转写的对照文件，文字版本保留。 |
| 编辑、复制和撤销 | 在旧版同时复现两种失败；修复后编辑撤销不再留下阻止识别修订的草稿，删空草稿仍保存。复制最近有正文的组；清空后不会回取旧文。146 项 AppModel 检查通过。 |
| 长期档案 | [十万条合成档案、三十万版本](storage-scale.json)，清理 499 条元数据的同时保存草稿 P95 为 0.31 ms。实际文件保护另用小样本实测。 |
| 本地中文实时识别 | [Google FLEURS 中文公开测试集](https://huggingface.co/datasets/google/fleurs)，CC BY 4.0。冻结语料版本、行号和校验和见[收据](public-speech.json)。一段 11.62 秒素材按原速进入签名产品、Apple SpeechAnalyzer、AppKit 和临时 SQLite；从估计的发声起点 1.398 秒看到首字，发声结束前有 19 次不同文字，最终 0/29 字错。这是单例，没有调用云服务、没有现场真人麦克风结论。[原生窗口](public-speech-window.png)。 |
| 窗口与按钮 | [签名产品](native-controls.json) 58 次真实控件操作、9 次菜单操作、收藏重启和同一窗口切页通过；没有观察到前台应用切换。 |
| 浏览器目标 | [读取小型已知测试页面](ax-read-cost.json)的两版各 100 次检查均身份完整，P95 从 0.63 降至 0.47 ms。该数字不是 Chrome 端到端延迟。首轮产品 CI 的真实 [Chrome](first-ci-chrome.log) 和 [TextEdit](first-ci-textedit.log) 通过；[WKWebView 首轮](first-ci-input-foreground-batch.log)在初次绑定时安全拒绝，没有写入。 |
| Nearpane | 独立的托盘测试不再阻塞主线程，语音宿主的原 2 秒截止和所有断言保留，[同一 CI 319/319](https://github.com/haohongfei2001-png/nearpane/actions/runs/43358512862/job/131666190992)。没有安装 Nearpane；独立网站预览不是原生验收。 |


先前前台测试准备窗口时会先挂一套临时 AX 观察器、随即拆下，然后生产绑定再安装观察器。现在目标只由一个正式绑定观察；夹具分别要求绑定前三次完整快照和正式绑定期间三次没有变化的快照，并检查三个必要通知的支持。隐藏 WKWebView 的正反例证实，同 URL 的页面内容在观察期间被静默替换时，绑定被撤销、零写入；[观察结果](owned-observer.txt)。TextEdit 和 Chrome 作业步骤分别保存成功或失败。调整限于验收，不更改签名应用。


授权撤销的测试现在等合成凭据读取确实开始再撤销；此前用例若 3 秒内未等到上游 ASR 定稿，可能根本没有进入要验证的读取。读取前会话结束仍明确失败；测试、阻塞读取和完成均有各自时限，保留撤销后零外发、原音完整等断言。没有读取真实 Keychain。

# 实时时钟观察

本轮运行源码为 `0a0cdecab8eb099e1dc3bb21b4c15ba5c30c93f0`。恢复或核查时，先检查 [72 小时驻留进程](soak/interval.json)和[两小时本地识别进程](active/start.json)的身份。原始观察在运行机器的冻结工作树，各阶段只发布已经产生的独立快照。生成文件与数据均来自专用临时目录。

两个运行完成后，[有限的收口程序](ops/finish-observations.py)分别读取生产者写出的结果，将逐项 PASS / FAIL / BLOCKED、原始采样与哈希写入本轮快照，然后非强制推送到 PR #6。源码或发布环境发生变化时，实际本机收据仍可重读，推送失败另外记录。主机重启或测试进程丢失后，缺少终态的观察不能补记为 PASS。长跑包含系统睡眠时段；最大采样间隙和内核睡醒事件单列。

`report.py` 汇总数据时使用被冻结工作树中的原始 App、DMG 和收据。App RSS、内核物理内存、CPU 归因能量与整机功耗分别统计。两小时负载只接收两条现成合成语音，驻留测试打开单独空库，均不读取个人历史或申请系统权限。

# 内测 0.12 · 菜单栏与语音板

安装源码 `a4f9f08656d1a22d2e0b6c59ad60e36452881010`，build 373。原包的服务状态曾调整菜单图标透明度，出错时还会将宽度从 18 pt 改为 25 pt。可见窄板同时满足原先「展开」与「收起」两个分支。

状态项现在用同一枚 20 × 20 pt 单色 tile，保留用户批准的字形。单击打开菜单。语音板可见时菜单提供「收起语音板」，隐藏时提供「展开语音板」。重新展开沿用原先的窗口尺寸和位置。窄板语音键的快捷菜单另有「恢复阅读尺寸」。收音状态继续由板上的语音键表示。

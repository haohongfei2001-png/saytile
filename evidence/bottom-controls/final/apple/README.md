# Local Apple Speech corpus

The installed Apple Speech framework completed **all eight synthetic Mandarin cases** through the production local recognition path. The files contained 48.7029375 seconds of generated speech. Each produced 21–31 local candidates, unified evidence and a dispatchable revision. The executed probe and generated fixture hashes matched before and after the run. Per-case references, transcripts and timing events are in `apple-corpus.json`. `apple-summary.json` and `receipt.json` bind the metrics and inputs to `455143310222c2c03c4a4888e5df5552c3af4131`.

The same executable checked the official framework inventory before corpus execution. It initially reported Chinese speech supported and the module not installed, with zero of five locale reservations used. One production `AppleSpeechService.prepare()` call completed. The next inventory check showed the module installed and the target using one of five slots. The wrapper imposed a 180-second preparation deadline and made no locale-release call. No OS prompt or microphone input was used. The observed inventory transition does not determine how many bytes were downloaded. Exact pre/post framework state is in `asset-preparation.json`.

The retained corpus probe differs from `tests/fixtures/AudioCorpusProbe.swift` only at the optional preparation call, where the observer records inventory state and applies the deadline around the existing production method. `probe-source-identity.json` identifies both source versions and the observer. The synthesis inputs, transcriber path, candidate storage, normalization and score calculation are otherwise identical.

Normalized CER ranged from **0 to 0.2631579**. The mixed-language case missed `Mac`, the pause case missed `保存原音`, the second voice missed `充电器`, and the correction case missed `修改开始时间`. Median first-text time was **1.20199 seconds**. Median completion time measured from paced input EOF was **0.05362 seconds**. These measurements describe the local engine on generated speech. Natural-speech accuracy, real cloud performance and the improvement from dual-expert fusion remain unmeasured.

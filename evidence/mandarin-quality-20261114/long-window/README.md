前两行的发布次数只算包含新增参考双字的源发布。第三行只报声学终点前的全部发布。前两行有效发布间隔 P95 分别从 2.89→2.07 秒、4.07→2.00 秒。首条新助手首发慢约 1.14 秒。每个样本只做一次新旧对照，无法据此判断长期首字分布。原始结果中的最终负载、版本和 SHA 供独立复算。

Qwen 先按原步长推理并返回第一个实际非空候选。当旧预览消耗的时间长到下一批音频已在管道中，接收端可将完整可读的数据包连续并入下一次解码。下一包只有部分头部或正文时，保留已收字节并立即返回当前数据。最多追赶三个额外步长。EOS 与满 32 秒边界照常解码，其他模型仍使用自己的原有路径。该修改会影响过载时的临时显示节奏。长期效果由最终安装包的原速测试单独验证。

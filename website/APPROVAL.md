## 必须保留的页面与行为

1. 首屏标题「让每句话，准确留下。」及原文、换行、字号、字重 500、字距、留白；正式图标与白色玻璃语音板、两枚按钮、柔和环境光、多层阴影。
2. 一份连续文字；自然口述中的停顿与补充。三角、圆点、五根圆头竖条表达暂停、待命、讲话。讲话完成后回到圆点。
3. 语块渐入、首屏轻微指针视差、局部「在→再」修订及短暂高亮、滚入过渡、时间轴追加与回看。动画完成后不自动反复重置。
4. 复制选区或当前全文、复制成功反馈；聚焦暂停与实际编辑区分；用户修改不会被自动演示覆盖，仅明确重播才恢复示例。
5. 「忠实表达 → 随时继续 → 说完之后 → 内测入口」整页结构、时间轴、原音说明、深色收尾、常见问题与真实 GitHub 链接。
6. 完整响应式断点、键盘焦点、ARIA 语义、跳转正文、后台暂停与 `prefers-reduced-motion` 支持。

具体尺寸、时间、缓动、色值、阴影与断点以冻结源文件为准，不靠本文摘要重新实现。

# 官网接续规则

正式入口 https://saytile.com/；权威目录 website/。先读 README.md、APPROVAL.md、snapshot.json 和 VALIDATION.md。

- 当前正式首页为R8保留部分加用户批准的新复制及档案两段。R3六文件冻结说明属于历史，不得用旧版覆盖当前首页。
- 运行源码是设计与交互权威。保留已认可首屏、持续表达区、深色结尾；用户明确要求的新修改优先。
- 脚本顺序为panel.js、hero.js、middle.js、scenes.js；样式包含panel.css和scenes.css。旧app.js不再被首页加载。
- 改运行文件后更新SHA256SUMS.txt与snapshot.json。历史截图不替代当前完整实现。
- 保留暂停、人工编辑保护、键盘与减少动态效果；自动演示不写系统剪贴板、不发送消息。
- 档案为本页示例，音频为标注的TTS，不宣称未验证的云同步；网页验收不是原生App验收。
- 保存当轮实际检查及环境，不继承别版测试计数。

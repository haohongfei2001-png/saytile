# 官网接续规则

本目录是用户于 2026-11-13 明确批准的 Saytile 正式官网。先读 README.md、APPROVAL.md、snapshot.json 和 VALIDATION.md。

- 运行源码是设计与交互的权威，reference/ 的截图用于对照。保留完整样式和脚本，不依截图重新实现。
- 当前六个运行文件来自已发布的 R3，SHA256SUMS.txt 记录其冻结值。改动前说明具体原因，并保持可追踪的增量提交。
- 保留原文、正式图标、玻璃材质、文字节奏、三态图形、编辑保护、复制行为、响应式和 reduced-motion。未经用户要求，不做整体重设计、换模板、替换图标或删除动效。
- panel.js 先于 app.js 加载，均使用 defer；不要遗漏 panel.css。
- 本目录是官网演示，不能把其状态、截图或浏览器验收当作原生应用能力的证明。
- 用户最新明确指令优先；本文件不阻止用户授权的后续修改。

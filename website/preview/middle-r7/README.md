# Saytile R7 · 克制白底中段预览

候选：https://saytile.com/preview/middle-r7/

用户要求：首屏克制很好；中段不精细精致、缺少设计感和动效，不应大面积铺紫色。

本版只新增独立预览，正式根首页不改。首屏与结尾源码逐段保留；原 styles.css、panel.css、panel.js、hero.js 与图标不变。

设计改为中性白与极浅暖灰，删除紫色场景框及大面积薰衣草分区。紫色仅用于状态、光标、局部修正及真实原生档案自身的配色。重新组织连续白底构图、精简重复标题、调整字重行距、玻璃细边缘、近白反光、阴影和移动端比例。

动效：语块渐入、波形转为待命圆点、细微玻璃反光、指针响应、原位单字修正、示例文字移入草稿、原生档案首次进入取景。用户操作后停止自动干预；减少动态效果保留完整内容。

网页不访问麦克风、ASR、用户剪贴板读取或外部应用，不发送消息。只有显式复制才写系统剪贴板。连续输入只在本页面示例草稿中运行。

档案为原始PNG（blob ee42ef0c9812e2931b1f8e43638236e517037443），没有重编码。主板是网页演示，不冒称实机录屏。纯静态、无第三方依赖和付费API；noindex。可在本目录运行 python3 -m http.server 8080。

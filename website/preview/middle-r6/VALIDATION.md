# R6 实际验证

43 项浏览器检查通过。执行环境为隔离 Chromium 144 / Linux，HTML、CSS、JS 和图片按本地原件内联到页面，因为该工作容器禁止 HTTP 导航。未将此阶段称作公开网络或 Safari 验证。

已检查 320、390、650、768、850、1024、1440 CSS px：无横向溢出。另检查原位核对、状态切换、口述计时与暂停/恢复、减少动态效果、人工编辑保护、复制回退返回值、示例粘贴保留原草稿、明确目标绑定不重放历史、增量追加、改字后解绑、键盘切换、原生大图与 Esc 关闭和焦点恢复。

图片通过完整解码；档案图片的 Git blob 与原生来源逐字节相同。首屏和结尾源码逐段比较完全一致，四个复用的视觉/脚本资源保持原始摘要。源码本身与响应式页面截图分别检查，截图不会替代原生 App 验收。

首轮测试发现：在完整演示结束后，“继续”会误将人工编辑作为重新播放的输入重置。已将“继续”与显式“从头重播”分离，并复跑全部 43 项检查通过。未放宽编辑保留的断言。

本地阶段验证了显式复制的浏览器回退成功反馈，不等同公开 HTTPS 系统剪贴板读回。公开网络、macOS 浏览器与线上资源检查应以另行执行的记录为准；不沿用 R4/R5 的检查计数。

桌面与手机宽度截图来自实际 Chromium 渲染。手机宽度不是实体 iPhone 验证。网页演示不访问麦克风，不调用 ASR，不操作用户其他应用，也不发送消息。

## 这次改动

保留已批准 R3 的 Header、Hero、结尾、FAQ 与 footer 源码。中段以同一段表达贯穿连续口述、原位核对和文字取用，最后展示原生语音档案。删除此前预览的虚构整套桌面、说明流程箭头和压缩失真的小截图。

- 连续表达：一个符合已批准形态的无标题、两按钮语音板，文字随语块进入，停顿回到待命，再开口接续。不将文字拆成逐句卡片。
- 忠实核对：原位置改变一个字，保留口语与补充；演示不运行 ASR，也不宣称识别质量。
- 文字取用：显式复制写入浏览器允许的剪贴板；“粘贴示例”使用本页刚复制的示例，不读取用户剪贴板。连续输入示意只绑定当前网页中的 textarea，只追加新的示例句，编辑或光标变化后需重新绑定。
- 原生档案：使用完整原始 PNG，浏览记录与单段详情，可放大查看；这是实拍而非网页重建的原生界面，不把截图中的按钮伪装成网页操作。

源代码只操作本页示例。自动播放取用过程不会写入系统剪贴板；用户一旦编辑或切换模式，不再自动覆盖。

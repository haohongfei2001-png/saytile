## 新中段

- 工作场景：写作、阅读、向 AI 提问是可切换的工作背景。同一块窄语音板在桌面一旁，正文从首行开始，只有复制和语音状态两个按钮；不把它展示成聊天机器人或润稿器。大屏桌面示例中面板宽度是示例桌面的 1/8，手机采用局部取景而非缩小整个桌面。
- 忠实表达：四个自然语块接续出现，在同一处把「平审」修正为「评审」，保留「嗯」、语气和补充，不出现多份候选稿。手动回放、暂停和实际音频播放器均可操作。
- 历史取用：三条合成示例档案可真实检索、选择、编辑、复制、回听。编辑仅保存在当前页面会话中，切换记录不丢失，不宣称网页保存了私人录音。

所有正文、录音和工作窗口均为演示，不访问麦克风，不运行 ASR，不自动发送，不调用收费 API。音频使用系统中文 TTS 合成并明确标注；波形来自该合成样本的 RMS，非真实用户录音。演示音频只在用户点击后播放。

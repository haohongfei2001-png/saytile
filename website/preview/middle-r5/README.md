# Saytile · R5 中段设计预览

状态：独立设计候选，未替换正式首页。

预览地址：https://saytile.com/preview/middle-r5/

## 产品依据

本版回到 Saytile V1 的真实产品定义：
- 常驻待命；停顿后回到待命，收起输入板不停止收音，明确暂停才停止采集。
- 自由记录与直接输入是两种不同取用方式。直接输入需要用户明确绑定目标，只追加之后稳定的新文字；目标变化时暂停，不自动发送、不盲目重放。
- 语音档案按讲话段落组织，支持搜索、编辑、文字版本、回听原音、重新识别与带回输入板。
- 原音与文字独立保存；单独删除原音不会删除文字与修改稿。

## 页面范围

- Header、R3 首屏 Hero、R3 结尾/FAQ/footer 沿用原始 HTML；仅为预览目录调整相对资源路径。
- 中段改为三个连续章节：持续表达、两种取用方式、语音档案。
- 输入板与档案均使用真实原生界面隔离示例资料；不是合成 UI，也不是用户私人录音。
- 首屏与中段的文字流交互均为行为示意，不访问麦克风、ASR 或外部应用，不宣称网页功能等于原生功能。
- 新页面 noindex；正式根首页、现有域名、Pages 配置和原 R3 运行文件不变。

## 本地预览

运行：python3 -m http.server 8080 --directory website/preview/middle-r5

页面依赖仓库根目录的 styles.css、panel.css、panel.js 和正式图标；无需构建、后端、字体或外部 CDN。

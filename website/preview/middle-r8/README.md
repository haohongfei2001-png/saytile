# Saytile R8 · 微光与连续表达

独立设计预览：https://saytile.com/preview/middle-r8/

最新反馈：仍然粗糙、不精细精致，缺乏设计感和动效；克制不代表完全没有颜色。本次沿用已认可的首屏和结尾，不替换正式根首页。

## 设计

中性白为页面背景；颜色集中在半透明声波材质、玻璃边缘、局部暖桃/雾蓝反光、文字重点及纸张叠边。三段分别采用动态产品场景、文字递交、开放式时间流，不再重复同一种卡片布局。

首段主体始终只有一块无标题、连续文字与两按钮的语音板。外部五根玻璃竖条和点阵为装饰性声音可视化，随演示说话/待命改变，不是额外应用控件或真实麦克风采样。文字按同一时间线逐步出现、停顿、续接，支持暂停与明确重播。人工修改包括空文本被保留。

第二段显式复制使用安全上下文剪贴板API；自动文字递交只是本页示例，不写入剪贴板。连续输入需明确选中本页面草稿，只追加新句；目标值或光标变化要求重选。编辑、模式切换和重置会取消过时的示例粘贴。

第三段是可检索、切换、编辑和回看版本的示例时间流。内容仅存于当前页面会话。没有假播放按钮或合成音频；原生语音档案可在大图中查看。原始PNG沿用Git blob ee42ef0c9812e2931b1f8e43638236e517037443，2100×1344，不重编码。

## 边界

这是设计候选，不自行认定用户批准。无麦克风/ASR/第三方请求/外部应用控制/自动发送；不接触用户音频、数据库、真实草稿或付费服务。页面noindex。原生App与识别能力的验收不由此网页代替。

Header、Hero、结尾和FAQ的HTML按段逐字节保留。styles.css、panel.css、panel.js、hero.js、图标、原生档案PNG均保持R7原件。仅独立目录中的index.html、middle.css和middle.js重做。

## 运行

本目录纯静态、自包含。运行 python3 -m http.server 8080，再打开 localhost:8080。正式HTTPS下复制可由浏览器权限控制。无需Node构建、字体安装、CDN或后端。

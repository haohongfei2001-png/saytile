# V1 验收：不能把设计验证当产品验收

## 本轮已执行

10 项继承的 Linux 合成 PCM/SQLite 故障实验；37 项重建契约测试；48 项 Chromium DOM 交互检查；Swift 6 类型检查；6 个 Foundation UTF-16 断言。

所有输入均为合成数据或原型示例。浏览器的 localStorage 是明确的测试替身。测试工具不访问真实麦克风、不请求系统权限、不往用户真实聊天写字。

## 原生 P0 必验

| 场景 | 通过条件 | 当前状态 |
|---|---|---|
| 30 分钟连续讲话 | 不逐段重启；原音范围可追踪；已有文本保留 | 未测 |
| 识别器阻塞/失败 | 新声音继续落盘，待识别队列有界，故障不扩散 | 未测 |
| 进程中断与恢复 | 已确认持久化范围恢复；尾部损失如实记录 | 仅合成模型验证 |
| 删除原音 | 全部文字、修改稿、搜索仍在；原音清理状态准确 | 契约/DOM 已验，原生未测 |
| 连续直接输入 | 稳定新范围只派发一次；前缀改写不重发全文 | 契约/DOM 已验，AX 未测 |
| 目标/聊天变化 | 不错投、不重放；新记录继续进入工作台 | 模拟已验，真实 SPA 未测 |
| 断网/语言包故障 | 采集与原音保存不依赖识别可用；文字可延迟 | 未测 |
| 麦克风断开/休眠 | 中断可见，重建时钟域，不悄悄换设备 | 未测 |
| 存储不足 | 不虚报已保存，不静默丢弃保护内容 | 模型局部验证 |
| 后台待命与功耗 | 测整机差值与模型服务，不只看主 App CPU | 未测 |

原报告 3% 单核 CPU、1.5–2 秒首字、2.5 秒停顿定稿、0.5W 待命等均为早期设计预算，不是这轮性能结果。不得标成已达标。

## 发行前附加验证

多显示器/Spaces、锁屏与唤醒、无辅助功能权限、签名公证、首次下载失败、升级保留资料、72 小时长期运行、未确认输入无自动重放、共享块重写正确性、真实中文修正量。

应由工程方在隔离样本/测试账户内执行，不把用户作为默认测试员，也不要在用户真实草稿里发送测试消息。

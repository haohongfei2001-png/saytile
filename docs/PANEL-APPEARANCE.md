# 语音板外观 · 内测 0.19

用户授权外观配置；入口为「语音档案与设置 → 语音板外观」。主板仍只有正文和原两按钮。

- 面板：原色、雾蓝、暖白；按钮：紫色、蓝色、石墨。
- 透明度：通透（默认）、柔雾、浓雾、不透明。无滑条，不把模糊等同于窗口整体alpha，文字/按钮始终清晰。
- 字号：小12pt、默认14.04pt、大16pt、特大18pt。窗口缩放不改变字号或按钮几何。
- 默认大小：紧凑、默认、宽敞。默认沿用已有可见桌面几何；另两档0.85×/1.35×，受屏幕边界约束，保持当前右上锚点。选择立即应用；「恢复所选大小」可撤销手调尺寸。
- 显示边框沿用旧偏好；「恢复默认外观」恢复原色、紫色、通透、默认字号/尺寸和边框。

`VoicePanelAppearance` 属于共享呈现包；默认环境使未升级的Nearpane宿主仍用原样。仅Saytile宿主加载独立UserDefaults并注入，不混合两App状态。新偏好损坏则回到现有默认；数据库、原音、Keychain及模型未变。

全屏仍加强遮挡，各档不比自己的常态更透明；减少透明度系统偏好优先。字体改变保留字符锚点/选区；IME组合输入完成后再应用新字号。

## 验收边界

AppModel重启/旧边框/损坏偏好、共享材质/字号/IME、窗口几何分别验证。真实设置菜单、窗口尺寸通知链、合成背景上的玻璃合成、升级回退使用隔离资料。最终收据将绑定产品源码SHA与DMG指纹；不重新运行未改的模型排名，不把截图当用户审美确认。当前签名原生/完整CI仍待执行。

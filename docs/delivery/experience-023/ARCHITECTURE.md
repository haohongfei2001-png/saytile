# 0.23（571）Qwen 主线收口

当前产品源码 `a1ac008de50855ae0c03f30128f5b1f74269d617`。本次只沿用 Qwen，不重跑模型选型。

唯一进入生产的性能优化是同一 tokenizer 的等价加载：Foundation JSON 桥接改为原生字典解码、预留字典容量、按 UTF-8 解析已有 BPE 合并表并复用原行作为键。权重、token ID、合并顺序、推理参数、窗口、VAD、最终解码与发布规则不变。固定上游 revision 和补丁由 `prepare-local-runtime.sh` 重建，避免本机缓存掩盖不可复现的依赖。

worker 仅在既有测试计时开关打开时记录单调启动阶段；原生探针记录自有面板可见性、跟随、选区、编辑/输入法保护与待显示状态。观测不改焦点、范围或 UI 保护。

本轮试验未满足安全/体验条件的方案不进入产品：全候选限频仍会扣留新讲话；重复 2/3/4 次的前缀仍与 EOS 冲突。Qwen 临时预览继续 `stableUTF16Length == 0`，外部输入仍须等待 EOS。这是明确的产品限制，不能称为边说边输入外部应用。全部真实候选和失败原件见 [本轮收口验收](CLOSURE.md)。

# 0.23：选择中文质量，分离预览与正式输入

产品源码 `5ebff045ff10c34dbbe12ce5235e3cef4f6d07a0`，独立 Draft PR #54，父分支为 PR #53。本轮只有既有 Qwen 0.6B 和 Nemotron 3.5 两条路线，没有增加生产 ASR、模型搜索或 Metal 实验。

## 产品裁决

**继续采用 Qwen 0.6B；保留临时预览与稳定文字分离的方向。当前 Nemotron 不进入中文消费者默认目录。** 原型有实际长句响应收益，尚不能声称所有首字长尾、临时回改或现场语音问题均已解决。候选继续 Draft / HOLD，不替换已安装 533。

相同 15 段原速中文：Qwen 为 46/568 错误（8.10%），Nemotron 为 186/568（32.75%）。相同 420 段完整语料：Qwen 910/10663（8.53%），Nemotron 2713/10663（25.44%）。Nemotron 更低的 CPU、内存和 EOS 延迟不能抵偿漏词、错词，尤其不能把不可回改的错误当成稳定性优势。这是当前固定权重、适配器与测试集的结论，不是所有 Nemotron 实现或所有语言的排名。

## 实际实现

音频、VAD、PCMJournal、SQLite、SingleTranscriptEngine 与单路调度不变。Qwen 仍使用已有滚动批量解码，Nemotron 使用已有持续会话和 cache-aware 流式解码。每段只有一个活动 ASR，比较时也串行运行。

`LocalLiveText` 增加两种内部预览策略。旧 `confirmed` 仅用于同候选离线对照；生产调用选择 `provisional`，不再让旧词的阅读确认前缀扣留整个后续候选。保留同长度、孤立尾词变换的再观察保护。发布的文字只能来自当前原始模型候选，保留既有末尾句号抑制，不拼接旧词与新词，不生成占位文字。

Qwen 每次非最终候选的 `stableUTF16Length` **仍是 0**。临时文字显示出来不等于获得直接输入许可；只有原有稳定性/最终条件及目标归属检查通过，才允许进入外部应用。EOS 使用模型原始定稿，不用预览倒推出定稿。用户编辑的优先版本、原音、版本历史和未知投递的拒绝重放不变。

原生连续文字控件给 `preferredOrigin == .partial` 的文字使用同色 60% 不透明度，正式/编辑文字恢复正常墨色。颜色不改变字号、行高、布局、选区、焦点或剪贴板。即使最终文本与临时字符串相同，也更新样式。没有增加第二份文字、常驻说明、按钮或新的语音状态。共享组件给其他宿主提供默认 `isProvisional = false`，不强迫宿主改变数据层。

## Nemotron 的真实适配问题

固定权重 `aufklarer/Nemotron-3.5-ASR-Streaming-0.6B-MLX-8bit`，revision `5339193d26b1eda4461358c6210f5039e97af213`，总文件 768,144,398 bytes。原有 `language: "zh"` 在该包中不存在，会静默落到 `auto:101`；`zh-CN:4` 才是包中的普通话提示。两处创建/重置会话均改为已验证存在的 `zh-CN`，不存在则明确配置失败。原始 `auto` 测试保留，15 段 CER 为 27.64%；明确中文提示并没有救回质量，反而为 32.75%。不选择性删除较差结果。

权重卡声明 OpenMDW-1.1；固定 MLX 运行库、分发声明沿用仓库已有依赖与许可证清单。来源、各文件 SHA-256 见 `evidence/experience-023/setup/nemotron-weights.json` 及原始模型卡。这里只评价现有 MLX 8-bit 包，未验 NVIDIA NIM、CoreML 或其他精度。Qwen 固定包为 712,777,119 bytes、revision `bc441bd1e4295c1f42d9879f056049a925b6e013`，Apache-2.0。权重不随基础 DMG 打包。

## 效果及边界

同一份最终长句的 72 个原始输出离线重放，旧确认策略最长有效新字间隔 1.971 s，新预览策略 1.526 s；首个候选相同、EOS 相同、全部临时派发长度为 0。该对照证明减少等待来自发布机制，而非换了音频、模型、评分或编造文本。

新策略会暴露模型真实的不确定性。当前长句往返旧词由 0 增至 1；另一个历史候选轨迹由 1 增至 10，完整保留。不能声称“彻底消除回改”。以旧词完全不动为目标冻结后续整句会伤害及时可读性；以所有预览立即正式输入则伤害安全。本原型将这两种责任分开，但不把产品取舍冒充用户最终视觉认可。

本轮不调整 VAD、分段、解码参数、温度、模型权重、主界面布局或输入所有权。后续只针对有证据的临时回改与首字波动继续优化；不因 Nemotron 名称含 streaming 就替换中文质量更好的 Qwen，也不以人工 5.33 核极端负载作为唯一发行门槛。

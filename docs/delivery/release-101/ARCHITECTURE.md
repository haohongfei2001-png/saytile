# 1.0.1 产品与技术变化

产品源码：`2d12129f2031fdf827d51fa1796d155e79243e07`，版本1.0.1（576）。继承[1.0.0架构](../release-100/ARCHITECTURE.md)。

识别仍为一段一个Qwen专家、单一文字引擎；临时面板预览与正式外部输入分离。没有修改Qwen权重、MLX解码、VAD、EOS、用户稿优先级或原音数据库。首次5.451秒异常的阶段定位与未证实部分见[性能记录](PERFORMANCE.md)。

首次使用在已有启动恢复结束后、MainActor上只展示一次模型准备页。标记先于展示回调写入；已有首次转写记录不再触发。页面解释用途、712.8MB模型下载、麦克风与可选AX权限；不会在启动时自动开始收音或要求AX。拒绝麦克风后的首次开始点击可进入既有恢复入口；运行中的暂停逻辑不变。

外部写入后的有限读回确认保留内部快照unsupported错误的类型，继续使用既有4次采样及两次完整证据。不重发、不自动聚焦、没有扩大写入前所有权条件；不完整或改变的目标继续失效并保留文字。

Sparkle使用2.10.1真实delegate selector处理Release Notes，要求feed已验签和HTTPS；SDK继续验证说明及归档签名。更新工具以原Ed25519信任链准备归档与签名feed。生产feed仍为空，公证阻断解除、重新装订及打包验收前不发布更新。

Bundle ID、Application Support目录、Keychain服务、模型缓存与更新公钥保持既有用户兼容性。验收仅用独立合成资料和已授权公开音频；实际533保持不变。

关于页版本直接来自签名Info.plist，不再为正式版硬编码“内测”前缀。574→575仅此展示与构建号改变；完整输入树对应及原始验收SHA分别保留。

576进一步区分不可读取AXRole与明确不可编辑。前者只允许原有已写入后的有限只读确认；后者仍立即失效。完整所有权、用户修改序列、目标变化、稳定范围和一次写入约束不变。该变更不涉及识别链路，最终独立审查及21项故障注入见本轮证据。

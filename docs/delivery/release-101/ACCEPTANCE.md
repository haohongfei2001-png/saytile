## 本轮实际产品修改

1. 新用户首次打开已有的模型准备页面，仅显示一次；说明本机识别、模型大小、准备进度、麦克风用途，以及可选直接输入所需的辅助功能权限。
2. 已拒绝麦克风权限的用户首次点击开始，即进入既有恢复入口；正在录音时暂停行为不变，不在启动时连弹权限。
3. 外部写入后短暂AX内部读取失败保留错误类型，在原有有限预算内重新取得两次完整证据。没有再次写入、自动聚焦、扩大窗口/光标/范围所有权，预算耗尽仍保留文字并安全停止。
4. 使用Sparkle 2.10.1真正调用的Release Notes delegate；说明、feed和更新归档继续分别验证签名。
5. 关于页显示实际版本号，移除给正式版本也加上“内测”的遗留文案。

没有修改Qwen权重、解码参数、VAD、发布确认、EOS、用户稿优先级或生产ASR数量；没有将未经证实的性能猜测放入产品。

## 性能限制必须披露

原15段首字P50/P95为1.031/1.543秒，本轮574为1.052/2.126秒；有效可见更新间隔P95为0.977→1.007秒。38.8秒长句最长有效可见间隔为2.405→3.085秒，模型输出侧同步出现约3.082秒间隔。原始观察保留，不能宣称全面无退化或“已根治停顿”。CPU合计57.19→55.42秒仅是单轮观察，不能宣称可重复节能改善。

此前5.451秒首显中，首次解码占4.231秒，模型输出到可见仅38毫秒；本轮诊断未复现该异常。CPU累计时间不足以解释整个墙钟延迟，GPU/分页/调度具体原因仍未证实。本机只有Command Line Tools，未运行Instruments；没有冒称已取得System Trace。

[性能记录](PERFORMANCE.md)与[独立原生结果复核](FINAL-REPORT-REVIEW.md)保留全部口径。历史420段8.53%实际来自加速回放，本轮已纠正并完成墙钟原速双臂验证，不删除空稿/困难样本或改变分母。

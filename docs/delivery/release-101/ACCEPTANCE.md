## 性能限制必须披露

原15段首字P50/P95为1.031/1.543秒，本轮574为1.052/2.126秒；有效可见更新间隔P95为0.977→1.007秒。38.8秒长句最长有效可见间隔为2.405→3.085秒，模型输出侧同步出现约3.082秒间隔。原始观察保留，不能宣称全面无退化或“已根治停顿”。CPU合计57.19→55.42秒仅是单轮观察，不能宣称可重复节能改善。

此前5.451秒首显中，首次解码占4.231秒，模型输出到可见仅38毫秒；本轮诊断未复现该异常。CPU累计时间不足以解释整个墙钟延迟，GPU/分页/调度具体原因仍未证实。本机只有Command Line Tools，未运行Instruments；没有冒称已取得System Trace。

[性能记录](PERFORMANCE.md)与[独立原生结果复核](FINAL-REPORT-REVIEW.md)保留全部口径。历史420段8.53%实际来自加速回放，本轮已纠正为墙钟原速重新执行，不删除空稿/困难样本或改变分母。

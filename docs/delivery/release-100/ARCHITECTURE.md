# Saytile 1.0.0 产品与数据路径

生产继承 #52 → #53 → #54，主线 Qwen3-ASR 0.6B MLX 4-bit。没有并行 ASR、词库、额外服务器或新的账号系统。

1. CoreAudio 固定输入设备及 PCM 转换；PCMJournal 独立持久化，识别或网络失败不阻止原音保存。VAD 管理原音子段，展示自然段不按每次 VAD 停顿强行换行。
2. 每段一个本地 worker；完整上下文滚动预览，EOS 使用原始精确解码。沿用 571 的等价 tokenizer 加载优化，未改权重、解码语义、VAD 或评分规则。
3. 全部原始候选写入 SQLite，即使某条暂不重绘。面板展示一个完整模型候选，临时文字着色不同；不拼接不同时刻的旧词与新词。旧词一致四次后的单次短暂反向变化最多暂缓一条，下一条开放，EOS 不暂缓。
4. 直接输入使用独立短语确认：至少四次不同音频窗口、至少一秒新增证据、完整内部标点后至少八字支持；数字、否定等需要六次及两秒。反向原始候选立即使旧派发证据失效。它是早期确认，不是永远不改的模型终稿。
5. EOS 与已经输入的前缀不一致时，只建立受保护的所属范围修正，不把整稿重新追加。光标、选区、窗口、网页语义、用户编辑、完整前后文或目标绑定变化时拒绝修改；不确定投递不重试，不自动发送。手动稿和原音独立保留。
6. AppModel 的面板刷新不等待 AX 目标确认；外部派发串行合并，继续用原有持久游标防重复。AppKit 文字及着色在一次编辑事务中更新，只改变必要的颜色范围。
7. SQLite 档案、历史修订、自然段和模型缓存沿用公开 0.18、533 的身份；升级与回退使用隔离合成资料验证，不扫描用户档案。

Bundle ID `app.saytile.mac.mandarin-candidate` 虽含历史候选后缀，却已是公开 0.18 的用户身份。1.0 不改它；产品显示名统一 Saytile。旧 RC1 的独立目录不自动合并。

Cloud/BYOK 保留明确授权边界；未配置即不运行。iCloud、付费云端及反馈在线服务不作为本次已验收能力宣传。Sparkle 保留同一公钥和更新源，本次优先通过官网及 Release 手动分发，不提前推送未经真实更新验证的 Appcast。

# Saytile 1.0.0（572）

Apple Silicon Mac 的本地中文语音输入。无需 API Key 或订阅；首次联网下载约 713 MB 的 Qwen 模型，准备完成后可离线使用。需要 macOS 26 或更新系统。

## 本版内容

- 整合 Qwen 0.6B 中文主线和 0.23 的临时预览：讲话时显示模型的真实候选，停止后采用模型原音定稿。
- 直接输入可以在讲话结束前逐步追加经多次音频证据确认的短语。临时预览不直接写入外部应用；目标或用户内容改变时停止自动操作，不自动发送。
- 面板刷新与外部应用确认分离，减少等待外部应用造成的显示阻塞；轻量限制局部旧词的往返回改，不拼接虚构句子。
- 连续文字可选择、编辑和复制；语音档案提供自然段、搜索、星标、回听及版本历史。原音、转写与用户修改分别保存。
- 产品名称统一为 Saytile，保留已批准的紫色/黑色外观、面板几何和设置。

## 下载与安装

下载 `Saytile-1.0.0-arm64.dmg` 和 `SHA256SUMS.txt`，核对摘要后，将 Saytile.app 拖入原安装位置。升级前退出正在运行的 Saytile，并保留旧 App 与资料备份。

**Developer ID 签名及安全时间戳已验证，尚未完成 Apple 公证。** Gatekeeper 直接打开检查结果为 `Unnotarized Developer ID`。首次被阻止后，确认来自本仓库且摘要匹配，可进入系统设置 → 隐私与安全性，为此 App 选择系统提供的“仍要打开”。[Apple 安装说明](https://support.apple.com/zh-cn/102445)。不需要关闭 Gatekeeper、移除隔离属性或执行安全绕过命令。受管理的 Mac 如不允许单 App 确认，请等待公证版本。

自由记录需要麦克风权限；仅直接输入需要辅助功能权限。不能验证所有权的目标会保留文字而拒绝自动修改，可使用普通复制。

公开 0.18 与内部 0.20（533）的应用身份、资料路径、模型缓存、Keychain 服务及更新公钥保持不变。旧 RC1 使用另一独立资料目录，本版不会静默迁移或覆盖。安装和回退说明见 `安装说明.md`。

本次通过官网和 GitHub 手动下载更新；没有把未经验证的新包推入 Sparkle 自动更新源。历史 Release 继续保留。

## 实际验收和限制

- 同一批 15 段原速公开人声，最终 CER 8.10%；完整 420 段 CER 8.53%。另列 20 段噪声/低音量派生样本；440 条最终文字及状态与 571 基线逐项相同。
- 38.8 秒原生识别到隔离真实 AX 输入目标，在 EOS 前完成 11 次确认写入；前后内容保持，零自动发送。
- 904.8 秒原速连续运行：44 条记录全部完成，原音与数据库关联完整，静音释放模型，继续讲话后恢复。
- 实际 0.18 与 533 的隔离升级、回退及重新升级通过；DMG 安装副本与实测 App 一致，损坏资源被签名校验拒绝。
- **仍可能出现首次解码等待。** 本轮一次短句首显为 5.45 秒，后续三组相同音频配对未重现；原始失败保留，不能保证所有启动都在两秒内出字。长句暂定文字仍可能自然修订，不宣称本次真实原速 A→B→A 数量下降。
- 本轮为同一 M5 上的公开人声原速原生验证；没有用回放代替用户本人现场讲话。合盖内置麦克风、8 GB 实体 Mac 未验收。
- 个别原有子段仍无法定稿，原音与重试保留；没有将空结果冒充成功。云端/iCloud/私有反馈服务未配置时不运行，本版不承诺跨设备同步或付费云端质量。

完整测试、原始失败、CI 和公开下载校验见 [发行验收记录](https://github.com/haohongfei2001-png/saytile/blob/main/docs/delivery/release-100/ACCEPTANCE.md)。

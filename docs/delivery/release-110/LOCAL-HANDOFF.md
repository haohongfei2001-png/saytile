# Saytile 1.1.0（578）本机接续

开发分支 `pro/release-110`，PR [#57](https://github.com/haohongfei2001-png/saytile/pull/57)。基于 PR #56 / `c7b7a994`，已经纳入1.0.1有效修复，不需要先发行1.0.1。源码与普通回归已由Pro实施；每次提交的远程结果见PR Checks，不把旧版15/420段成绩称作本版重测。

## 已确定的产品与代码

自然讲话 → 面板单一文字流 → 约30秒静音分自然段 → 一键复制。选中历史文字时取完整对应自然段，系统复制仍取选区。面板和详情页的普通复制均取完整自然段，详情页包含当前编辑稿；明确的历史版本复制仍保留。复制与保留的手动插入共用完整文本快照逻辑，包括屏幕外成员、用户修改和英文空格。历史段落身份不重组；短停顿与跨午夜不拆段。

Qwen继续正式主线。模型180秒暖保留；暂停、睡眠、退出、内存压力可提前释放，正在定稿时等本段完成。首窗合并已到达的完整PCM包，不等待新音频、不裁原音；权重、解码参数、VAD、EOS准确率策略保持。设置仅收起高级项目，面板几何和品牌保持。1.1.0安装包尚未发布；官网源码仍指向真实1.0.0下载。

## Codex只需完成下列本机工作

1. **取得准确源码。** 刷新PR #57与分支HEAD，在独立worktree构建，保留现有安装、资料和有效配置。使用现有 `scripts/build-app.sh`、`scripts/package-beta.sh`；不要重做产品研究、换模型或重写文字架构。
2. **实体设备短回归。** 实体麦克风自然讲话数分钟；5、20、29秒暂停继续同一段，约30秒以上后再说开启下一段。复制超屏自然段、选旧段、编辑后复制，确认继续讲话不因复制新建段。检验暂停/恢复、耳机或麦克风切换、睡眠/唤醒，保留原音和已改文字。未授予辅助功能时，记录、编辑、历史和复制应可用。对真实macOS窗口检查原几何、展开收起、选字/上滚时不抢阅读位置和设置折叠。
3. **少量真实性能对照。** 同一Apple Silicon、同一公开音频，对577与578做已有38.8秒长句的AB/BA/AB对照；复用 `scripts/mandarin/run-performance-pairs.py`（before/after/weights/audio/load-helper/out参数）及既有研究缓存。另验证45–90秒静音复用同一worker、195秒静音释放后恢复，使用已适配的 `scripts/test-local-idle-and-fault.py --model qwen-small`。记录首字、最大可见停顿、worker PID、RSS和可取得的能耗；不把单次更好写成全面提升，不强制重跑420段。首窗修复如实测明显回退，只修复或回退这一有限改动。
4. **签名与实际安装。** 使用本机已有Developer ID和可用公证profile，制作1.1.0（578）安装包，完成实际签名、公证/装订及Gatekeeper检查。缺公证凭据如实记录，继续所有不依赖凭据的构建、音频、界面和隔离升级验证；不得声称Apple已接受。对公开1.0.0及现有577用临时资料副本验证升级、回退与再升级，确认文字、原音、修改、收藏、模型缓存和设置保留。
5. **发布收尾。** 修复本轮实机确实发现的缺陷，再运行对应回归。通过必要安装验收后合并PR #57，发布v1.1.0、最终SHA256和安装说明，更新官网版本/体积/下载URL及实际公证状态，核对真实下载文件。只有经过原公钥验签、坏包拒绝和安装/重启验证的归档才推广到Sparkle稳定源；否则保留已验证的手动下载。无需为个别未测硬件增加无期限门槛。

# Saytile 1.1.0（578）本机原音诊断交接

2026-11-26。保留 **HOLD**。签名产品源码 `7eb459f1a07473ef3a2b66e6bba6b26cbc4f28ef`，复核 PR #57 的 HEAD 为 `410f1051caf78f7e0656151242e0c36624799609`。本次只对已经保存的本机档案取证。

## 可以下的裁决

首次现场验收的 13 条模型运行记录全部属于 Apple。另用签名 578 的 Qwen 直接读取同一批 PCM，绕开 VAD、网络和呈现层，仍是 8 段空、5 段各给出同一个语气词。可复现的故障已定位到“保存下来的音频交给模型时，已无法得到可验证的连续语句”。这项证据足以排除这些空结果由面板吞定稿造成。现场说话与内置麦克风之间、以及历史 VAD 之前的信号都没有留样，具体物理原因和现场是否漏收轻声仍待证。

| 改变的条件 | 实测结果 |
| --- | --- |
| 已保存 PCM | 13 段，904,640 帧，56.54 秒。最响的 5% 短窗占 97.74% 能量。独立离线声学分类覆盖 54.0 秒，95 个重叠窗口无一把语音列为首选。 |
| 已知来源的语音 | 同一权重在整体 RMS 比现场低 16.02 dB 的公开文件上得到 37 个有效字符。匹配到现场 RMS 后定稿仍逐字一致。公开对照的 19 个窗口中 14 个将语音列为首选。 |
| 保留间隔或缩短间隔 | 按档案端点估算时间、以零补间隔，定稿共 4 个有效字符。将间隔改为 250 ms 后共 2 个。两组均只有重复的语气词。 |
| 改变音量 | 有限 RMS 增益的 13 条定稿与原始逐条相同。逐段峰值归一化只多出一条 3 字短串，缺少可确认其正确的依据。 |
| 只改语言提示 | 同权重同一诊断前端，两种提示各 15 个输入含公开语音和全零对照。自动语言逐项复现签名 worker。强制中文使原本为空的 8 段产生与 5 秒全零输入完全相同的输出。 |
| 经过正式窗口路径 | 签名 578 明确使用 Qwen。10 段归档的 1,160,320 个样本在重建输入中的对应位置逐样本相同。10 次写管道和 EOS 帧数一致，10 次离线重解码均复现原生定稿。5 条空定稿均记失败，其中 1 条保留临时文字。窗口有 15 次显示变化，外部投递为零。 |
| VAD 边界 | 重放完整覆盖原始 13 段中的 12 段，另有一段 2.76 秒未触发。该段直接送 Qwen 也是空。补零会改变检测器的噪声状态，重放分段不能还原现场。 |
| 输入转换 | 5 组已知信号包含低电平、双声道和 48→16 kHz。实际 ring 与候选转换代码的结果都与独立连续 AVAudioConverter 逐字节一致，最大幅度误差 0.00253 dB，帧数全部吻合。原现场 48 kHz 流未保存。 |

同一权重附加做了一个可逆的能量分离试验。13 段的最响 5% 短窗与互补余量分别解码，26 次均为空，两个副本逐样本相加可还原原件。无法把那 5 个语气词单独归因于一次响声。

## 给 Pro 的最小修改清单

1. **验收工具**。把已验证的“明确选择模型，再从运行记录核对实际路由”保留为可执行回归。已有 `LocalStreamProbe` 可直接指定 `qwen-small`。现场控制器的修正已在此前附件中；优先将其可重复使用的部分纳入验收脚本。模型不符时中止该对照，单列已生成资料。普通启动的推荐逻辑无需随此变更。
2. **采集取证**。若要进一步区分声学输入与端点丢失，给隔离验收入口加一组同步计数。利用 `AudioTapCallbacks.recording`、`CaptureWorker.convertCapturedSamples`、`VoiceSegmenter.accept` 和 `FixturePerformanceTrace`，用同一帧序号记录设备格式、ring 丢帧、转换前后分级电平和 VAD 起止。用已授权的已知语音验证前后覆盖。只有在专用夹具中确需逐样本比对时，在本机临时保留 VAD 前的环形缓冲或双方 PCM 摘要。普通用户录音和常驻行为保持原契约。
3. **产品参数**。当前证据支持保留自动语言、空定稿可重试、原音及临时稿保留。对 `Worker.swift`、VAD 阈值、输入增益和文字发布器，本次没有可验证收益的发行改动。缺少现场 VAD 前资料，无法重建原话或计算个人 CER。

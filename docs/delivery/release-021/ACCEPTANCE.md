## 实际修复与没有采用的方案

- 修正模型已经发出空 EOS，却提示“模型未完成定稿”的错误。现在区分没有文字与没有最终定稿；保留原音、临时文字、用户编辑和可重试失败状态，不伪造成功、不切换第二个 ASR。
- 构建号独立存放为 564，避免整理 Git 历史后由提交数量计算出倒退的 Sparkle 版本。固定并核验 563 的签名运行库，包中模型仍按需下载。
- 修正隔离 Safari 测试页的首次光标初始化和主线整理遗漏的睡眠测试源。实际产品的窗口、光标、文本范围和所有权约束没有放宽。
- 验收脚本在进程失败前保存原生日志、原始窗口收据与资源样本。保留失败，不以复测结果覆盖它。
- 两轮发布器实验均没有可量化收益：局部锚点接续未改善已知 2.549 秒候选间隔；禁止旧变体回返的方案把停顿扩大至 8.948–9.914 秒。均未进入产品。生产发布器仍为 563 算法，不能宣称本轮已解决高负载停顿或降低 CPU。

# 最少账户授权

本轮不需要用户朗读、找日志、选择模型或反复点测试界面。Mac 按要求保持合盖，内置麦克风 NOT_RUN。以下是实际账户阻断，不是新增产品认证门槛。

1. **公证**：在本机 Keychain 配置一个经授权可用的 `notarytool` profile，提供 profile 名称即可，不在聊天/仓库提供密钥明文。Developer ID 已可用；后续提交、等待、装订、Gatekeeper 和新哈希由工程执行，不需关闭安全设置。
2. **iCloud**：Apple Team 为既有 Mac 和 iPhone App ID 关联 `iCloud.app.saytile.archive`，提供匹配的 Apple Development 身份及开发 profile。随后以独立合成记录验证 Mac 上传→新 Mac 恢复→iPhone 回听及删除，不上传私人录音。当前真实远端传输为 0 条 / 0 字节。
3. **反馈**：登录已有 Cloudflare 账户，完成既有多产品接收端的迁移和部署。Riftlet PR #104 的独立工作不被覆盖；远端尚未支持产品区分时保持 Saytile 发送关闭。本地草稿可用，真实私有工单、产品标签和删除尚未通过。

账户授权不自动意味着公开发行通过。高负载响应、合盖麦克风、8 GB、功耗和硬件恢复继续按实际证据列出，不能由 CI 或公证替代。

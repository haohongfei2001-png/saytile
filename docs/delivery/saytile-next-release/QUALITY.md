## 已安装 533 的原生确认

533 与上表 527 的识别器、发布逻辑、模型清单及 worker 相同；两者间的产品修改是选择性窗口避让。用最终 Developer ID 二进制原速重跑五个历史问题样本。五条均在讲话中多次显示，11 块原音和五份最终文字、复制结果均与 527 一致。这个困难子集含 204 个参考字，32 个错误（15.69%）；不能与全量 CER 混算。首个正确双字 P50/P95 为 0.689/1.080 秒，有效更新间隔为 0.401/1.078 秒，停讲到定稿为 0.028/0.097 秒。某条录音在 4.142、4.179、4.694 秒顺次显示「通」「通过」「通过红外」，EOS 在 15.502 秒。五例另有 2.406 和 3.700 秒的末尾静默或稀疏语音区间。此处五例与高负载长句的中段停显是两项不同观测。[终包原生收据](../../../evidence/internal-0.20-533/recognition/RESULT.json) · [当时的窗口](../../../evidence/internal-0.20-533/recognition/partial-native533.png)

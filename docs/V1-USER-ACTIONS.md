# 最少用户事项

工程开发、免费依赖、系统中文资源、构建和测试无需逐项批准，均已自主推进。

## 安装后一次完成

1. 打开个人 Beta，在输入板主动开启收音。若 macOS 提示，允许麦克风。当前工具启动的打包 App 已报告权限允许并通过硬件缓冲计数；不能据此保证 Finder 安装后的独立身份不再提示。
2. 如需跨应用插入，在系统设置 → 隐私与安全性 → 辅助功能中允许 Saytile。复制、档案、编辑和回听不依赖辅助功能。
3. 个人包采用 ad-hoc 签名，未 Developer ID 公证。首次下载可能需要本人在系统设置确认这一次打开；不关闭 Gatekeeper、不修改系统安全策略。升级若要求重新授权，按同一入口完成。

## 最少真实体验验收

- 在自己的麦克风下说一段普通话，停顿再继续，核对文字、回听原音及暂停/恢复。
- 在独立空草稿中启用直接输入，核对中文/emoji，切换页面后确认不会错投；不要用重要未保存内容作为首次验收草稿。
- 正常使用后反馈识别修正量及设备/睡眠恢复体验。工程没有假称真人中文质量、浏览器 SPA、30分钟真实收音、整机功耗或72小时稳定性已经通过。

中文资源在首次开启后自动准备。完整 Xcode 不需要安装。没有付费操作，也没有访问/上传私人录音、浏览器资料或聊天内容。

会话切换与休眠会暂停收音；锁屏事件不等同会话切换。本版锁屏自动暂停尚未保证，若需要锁屏前停止收音，请使用菜单栏暂停。

未保存编辑已加入本地持久草稿及切换/退出刷新，不需要用户额外手动备份或批准。若磁盘写入失败，App 会保留内存草稿并阻止普通退出，以便先处理存储问题。

工程已确认打包App展开输入板不会改变前台应用（独立启动探针通过），这项不需要用户重复检查。安装后仍需本人完成真实讲话和所用目标应用的最少体验验收。

当前远端编译器兼容和存储错误状态问题均由工程自行处理，不需要安装 Xcode、修改系统权限或用户协助。

存储错误收尾已由故障注入回归验证完成，用户不需要执行磁盘填满或故障模拟。遇到实际空间不足时，按App提示释放空间后恢复即可。

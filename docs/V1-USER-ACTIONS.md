# V1 必要用户事项

开发期间无需逐项批准。以下事项统一延后到安装与真实验收，工程先使用合成数据继续。

- 首次主动开启收音时，macOS 麦克风权限需本人确认；不会在后台自动弹出或伪造授权。
- 跨应用插入需要在系统设置中允许 Saytile 辅助功能。未授权时记录、搜索、编辑、回听和复制仍可用。
- 中文语音资产可用性、签名/安装限制、真实体验及长时间功耗结果将在实际验证后更新，不预先声称通过。
- 不进行付费操作；如无现成开发者签名身份，提供本机 ad-hoc 签名个人测试包并说明分发限制。

## 当前已消除的事项

完整 Xcode 不是前置；现有 CLT 已编译完整原生 App。Apple 中文资源已由工程使用免费系统接口下载并以合成音频验证，不需要你手动下载。

本机无有效 Developer ID 签名身份；个人包采用 ad-hoc 签名，不声称已公证或可在其他 Mac 无提示分发。不会购买开发者计划或修改付费方案。

原生49项测试与实际 SwiftUI 离屏渲染均无需用户操作，已完成。打包程序启动自检报告当前执行上下文麦克风状态为“已允许”；这不等于已验证安装后 App 身份或实际收音。不会据此虚构录音/AX验收结果。

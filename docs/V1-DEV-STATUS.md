## 本轮修复与取舍

- CLT 27 缺少 SwiftUI State 宏插件：明确使用稳定 State 属性包装器别名，可用现有 SDK 构建，不安装完整 Xcode。
- 工程所在 FileProvider 给 .app 添加 FinderInfo：构建脚本只清理自己生成包的扩展属性后签名，不改系统设置。
- 真实启动验证发现异步退出与 AppKit 终止循环死锁，改为完成清理后再次终止；已重新验证退出。
- 按记录独占音频目录，避免共享块物理删除问题；每个文件有连续样本，未使用共享音频块。

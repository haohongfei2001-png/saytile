# V1 开发状态

更新：2026-11-06。正式仓库 `haohongfei2001-png/saytile`。PR #1 已核验合并，原生工程 [PR #2](https://github.com/haohongfei2001-png/saytile/pull/2) 正在最终发布验证。

## 已实现

- 原生菜单栏、非激活输入板、档案、设置、可选快捷键、登录启动、随时暂停恢复。
- AVAudioEngine、预分配 C 原子环形缓冲、WebRTC VAD；自然开口、预录、停顿接续、连续分段。原音每秒同步、15 秒分块，保存与识别独立。
- Apple SpeechAnalyzer 中文流式识别、首次开启后自动准备免费系统资源、有限持久恢复队列、回听与重新识别。
- SQLite WAL/FULL 存储、版本与全文搜索、编辑草稿、收藏、容量提醒；只删原音保留文字，删除意图/租约/文件恢复及保护清理。
- 当前输入板只纳入本次表达和明确带回的历史。复制、目标绑定、局部插入、稳定 UTF-16 增量派发、未确认不重放、目标变化失效、不发送消息。
- 设备切换、休眠/用户会话切换处理、输入无回调看门狗、退出尾部排空。
- Swift 6 / macOS 26+ / Apple Silicon；CLT 完整构建、ad-hoc 签名 App、DMG 包装、原生及继承契约 CI。

## 已验证的事实

- 完整 App 编译、签名、启动/退出、实际 SwiftUI 离屏渲染。
- 打包 App 中 10.616 秒合成普通话识别成功，尾句及原音保留。
- 34.85 分钟加速合成负载保存 180 条；5 分钟实时生产 ring/转换/VAD/保存管线零丢帧、原音完整 300 秒，核心管线最大 RSS 20.4 MB、平均约 1.05% 单核 CPU。
- 实机麦克风硬件探针仅统计缓冲，不读取/保存/识别声音：49 buffers / 235200 frames / 48kHz。此前真实硬件发现 Swift 6 actor 回调崩溃，已修复并重新通过。
- 独立后台 AX 文本框通过中文/emoji 局部插入、UTF-16 位置及原文字保留；前台 PID 不变。它不是浏览器 SPA 或完整前台绑定验收。
- 原生测试、AppModel 集成验证及最新计数见 V1-TEST-RESULTS.md。

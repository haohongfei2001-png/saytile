## 2. 主面板：文字在上，两个操作在下

### 正文与顶部

- 顶部直接进入正文，不设置操作栏、独立状态灯、更多按钮或可见状态标签。
- 不显示 Saytile Logo、品牌字标、产品名、标题、头像或模型标识。
- 正文是一份连续、可选择、可持续修正的文字流，使用深色文字与舒适行距；可有克制的紫色光标。
- 不按句子拆卡片，不展示 ASR 候选、第二份修正版、模型名、置信度或润色结果。
- 识别与后续定稿更新同一份文字。用户选择、阅读旧内容或编辑时，不抢焦点、不强制跳底、不覆盖手工修改。
- 保存失败、权限中断、设备异常等真实问题可以显示必要提示；它们不是常驻日常状态文字，也不能伪装成正常待命。

### 底部固定操作

| 位置 | 常驻控件 | 作用与外形 |
|---|---|---|
| 左下 | 复制按钮 | 小型轻量图标；有选区时复制选区，否则复制当前文字 |
| 右下 | 唯一语音状态操作按钮 | 横向小胶囊；内部图形表达当前状态，点击负责开始/暂停/恢复 |

底部恰好两个常驻按钮。不得添加第三个编辑按钮、更多按钮、第二个语音开关或长条工具栏。编辑、档案、设置、直接输入、回到最新等已有能力通过上下文菜单及现有应用/菜单栏入口提供；不因收敛主面板而删除能力。

复制不会切换语音状态。状态与收音控制合并在右下同一个按钮内，不另放「状态图标 + 状态文字 + 暂停键」。无障碍标签、菜单与悬停帮助可以解释动作，但不把状态文案常驻在面板中。

## 3. 三个日常状态

| 状态 | 触发条件 | 右下按钮外观 | 点击行为 |
|---|---|---|---|
| 暂停 | 尚未开启收音，或用户已经暂停 | 静态播放三角；不显示波形 | 首次开始或恢复收音，成功后进入待命 |
| 待命 | 收音已开启，声音活动检测当前无讲话 | 安静、稳定的紫色圆点 | 暂停收音 |
| 正在识别 | 声音活动检测确认当前正在讲话 | 原图同类的五根圆头小竖条，高度随当前真实声音幅度变化 | 暂停收音 |

**「未开启」不再作为第四个日常状态。** 首次尚未开始与用户主动暂停使用同一个暂停外观；内部可保留是否曾启动的记录，以提供准确的「开始收音 / 继续收音」无障碍动作。

「正在识别」是用户看到的语音活动状态名称，不是后台 ASR/GPT 任务是否仍在运行的指示器。无声但仍有待识别、融合或定稿工作时，按钮应显示待命。

### 自动与手动转移

1. 点击暂停态按钮 → 启动成功 → 待命。
2. 声音活动检测确认用户开始讲话 → 正在识别。
3. **声音活动检测确认当前讲话结束 → 回待命，继续收音。** 不等待 ASR 最终结果、GPT 修正、EOS 定稿或历史识别队列清空。
4. 后台识别与定稿继续更新同一份文字；不出现「处理中 / 完成」第四种日常状态，不要求用户再次点击开始。
5. 待命或正在识别时点击语音按钮 → 暂停采集。自然停顿不等于暂停。
6. 暂停后点击同一按钮 → 恢复成功 → 待命。

「声音结束即回待命」指声音活动检测结束事件触发的切换，而不是识别完成事件。本规范没有新增或批准具体静音阈值；不凭设计图更改 VAD 时长策略，也不把事件处理描述成实测零延迟。

### 识别任务与语音活动必须独立

- 待命允许上一段仍处于 queued / running / fusion / finalization。
- 上一段尚未定稿时可以再次开口；新一段的真实语音活动决定按钮状态。
- 旧段迟到的结果、失败或完成回调不得把新讲话的波形重置为待命，也不得重新打开用户已经暂停的采集。
- 等待识别、网络延迟、历史重识别与后台队列均不得制造波形或持续占据正在识别态。
- 声音图形始终是圆头小竖条，不是波浪线或静止的波形符号。条高只使用当前采集会话的有效真实幅度；无有效幅度时保留最低条高，不伪造随机跳动或循环动画。低幅、短促、克制，文字仍是主体。

### 按钮内部的短过渡

- 三角与圆点双向变形；圆点与圆头小竖条双向变形；正在讲话时点击暂停，竖条直接收束成三角。日常状态不显示两根竖线的暂停图标。
- 只在原语音胶囊内部变形，不移动或缩放整个面板，不改变按钮尺寸，不新增提示或常驻控件。
- 状态变化采用短过渡：普通切换目标约160ms，进入暂停约120ms；真实音量更新采用约70ms插值。这些是视觉参数，不是实测收音延迟或必须播完的流程。
- 新声音事件或点击可以从当前可见形态立即转向新状态；不排队播放，不为完成动效推迟待命、停麦或下一次讲话。快速切换可自然缩短过渡。
- 待命圆点和暂停三角保持静止。开启系统「减少动态效果」时直接切换形态，仍及时显示真实音量变化。

### 启动与异常

启动中、权限不足和设备中断是技术过渡/异常，不扩充上述日常状态矩阵，也不新增第四种按钮图形。收音尚未启动成功时保留三角，成功后才变为待命圆点；准备过程必须允许取消。启动失败或设备中断保留三角及现有必要故障提示，不能显示成「正在正常等待讲话」。反馈仍使用原有语音按钮、帮助与无障碍描述，不新增常驻控制或第二个收音开关。

## 4. 视觉、尺寸与窗口行为

- 沿用紫蓝环境、薰衣草紫强调色、半透明浅色面板、深色正文。不得混入绿色、珊瑚橙或新的品牌方案。
- 右下控件是轻量横向玻璃胶囊，不是大型录音圆钮；左下复制控件较小，两个命中区域均须可用。
- 圆角、描边、阴影与模糊保持克制；正文不可受桌面背景严重干扰，不使用霓虹外发光或装饰性声浪。
- 空间优先给连续文字。移除顶部操作栏后，不用新的装饰留白占回腾出的正文空间。
- 主面板保持轻量桌面表达窗口，不改造成聊天窗口、AI 仪表盘、多卡片面板或横向工具栏。
- 文本增长后在面板内部滚动，不无限增高。阅读旧文字、选择文字或编辑时，保持阅读位置与选择内容。
- 收起面板不停止收音；用户通过语音控制明确暂停。可选桌面小入口只展开同一输入板，不是另一个文字面板。
- 右侧三个状态示例说明不同时间的外观，不同时创建三个窗口、会话或文字版本。图外注释不转换为面板可见状态标签。

## 5. 不可退化的产品契约

本次修改限于用户指定的状态呈现、按钮内部动效及相关验收；保留原设计，不改变识别、存储与外部输入架构：

- 持续收音，原音独立保存，一份忠实文字流；保存不依赖识别器或目标输入框。
- 两个平等完整音频专家与唯一文本融合核心保持现有契约，不新增模型链、翻译、扩写或润色。
- 用户的手工修改、选区、阅读位置与 UTF-16 范围所有权受到保护。
- 原音删除不删除文字；档案中的编辑、搜索、回听、重新识别与复用仍可达。
- 外部输入须明确绑定与授权，不自动发送、不敲回车、不覆盖用户已有内容，不重放不确定投递。
- 声音结束只改变主按钮外观，不取消上一段定稿，也不停止继续等待下一句。

## 6. 已失效的设计方向

以下内容均不能覆盖本规范：

- 顶部状态操作按钮、顶部更多菜单及独立状态标签。
- 「未开启、待命、正在识别、已暂停」四个日常状态。
- 「当前段识别和必要修正完成后才回待命」。
- 底部同时放复制、编辑和语音三个常驻按钮，或重复收音控制。
- PR #7 Sentence Fold、珊瑚橙/瓷白品牌方案及相关 Logo / 字标探索。
- 旧绿色原型、多候选版本、多模型状态卡与长条工具栏。

旧规范、旧 PR 评论及旧验证图片保留为历史证据，不重写其测试结果，不把它们作为新布局的通过依据。PR #8 仅是研究资料，不是设计权威。

| 短过渡 | 三角↔圆点、圆点↔竖条、竖条→三角自然衔接；新事件可中断；减少动态效果时不强制动画 |
| 修改范围 | 原图仍为视觉基准；本轮运行代码只替换语音按钮内部图形，不改面板材质、排版或控件位置 |
| 延迟定稿 | 声音结束但 ASR/GPT 仍 queued/running 时已回待命；文字仍可继续定稿 |
| 连续下一句 | 上一段未定稿即可再次进入波形；旧段结果不覆盖新讲话状态或产生重复文字 |
| 主动暂停 | 待命和讲话中均可暂停；晚回调不重启采集；恢复后继续等待下一句 |
| 其他能力 | 编辑、档案、设置、输入模式与回到最新仍通过菜单或已有入口可达 |
| 选择与阅读 | 复制不改语音状态；更新不抢选区、不强制滚动、不覆盖用户修改 |
| 异常 | 启动可取消；权限/设备/保存问题不伪装成正常待命 |

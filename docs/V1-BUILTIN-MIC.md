# MacBook 内置麦克风：个人体验修复

PR #17 的独立后续候选。仅验证 Apple 中文设备内识别；不改动冻结包、路由选择、识别模型或数据库结构。

真实故障：macOS 报告合盖时，已选定的内置输入仍被 HAL 枚举为可用，并送入全零 PCM。旧签名体验版两次打开该输入、显示「待命」；暂停后均释放了输入。现在仅在路由为内置且系统明确报告合盖时拒绝启动，运行中遇到同一条件则停机并按既有流程封存原音。正常安静、读取不到盖状态、非内置输入均不作为断开证据。依据：[Apple 硬件麦克风断开说明](https://support.apple.com/en-gb/guide/security/secbbd20b00b/web)。

真机上的合成噪声可令 Apple 中文 SpeechAnalyzer 返回 SFSpeechErrorDomain 1、描述 RecogRejected。错误码 1 同时用于其他内部故障，不据错误码概括。历史详情仅将确切的 RecogRejected 转为可读提示，不改写 SQLite 中的原始错误，不在原音删除后承诺回放。

基线的 4 种公开 FLEURS 受控输入（短句、长句、停顿后第二句、降低 18 dB）均在讲话结束前多次更新实际原生文字视图。应用端回放不会证明物理麦克风收到了现场声音。当前现场自然讲话、经内置麦克风的首字时延与主观准确度未验收。不提交个人资料、音频、历史、设置或凭据。

## 安装后回归

同一开发者签名、同一本地体验身份的应用实测：两次通过正式按钮请求收音，均显示具体中断原因；28 次 CoreAudio 进程观察均未打开任何输入设备。受控公开语音在最终签名包内重复运行：短句、长句、停顿后的两句和降低 18 dB 的短句在语音窗口内分别更新 7、12、7/12、7 次，归档顺序和原音覆盖范围正确。时延仅代表文件按原速馈入，不是麦克风端到端成绩。现场自然讲话未验收。

独立时间轴测试曾提前把最后一帧动画当作空闲结束：滚动坐标从 2117.556 到 2118.000 点，复制文本、云端修订后用户编辑、选区、收音状态与提示均未改变。验收改为等到原生滚动视图实际抵达布局目标，再记录锚点；保留点击后的精确相等断言。此改动仅在隔离 UI 验收模式运行，不改变普通体验版行为。

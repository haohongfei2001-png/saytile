# 自然段与时间组 · 内测 0.15

本轮基于已安装0.14（478），产品源码7fd9296d8eb2bd81379bbaa7287844d0d46703d5；独立分支codex/natural-paragraphs，未改main或其他任务。目标是主板与档案共同使用自然段，而不是分别过度连接、过度切碎。

## 行为

- 实际讲话间隔不足15秒，下一片文字接在同一自然段。达到15秒，下一次讲话开始新自然段。未讲话时不凭空添加空行、不挪动阅读位置。
- 时间组默认60秒，较长的现有用户设置保留。旧120秒默认升级到60秒；历史原有时间组保留。时间只在档案显示，频率低于自然段。
- 阈值使用录音实际开始、讲话结束时间；不使用ASR返回时间、网络延迟或人工修改时间。跨日/时钟回拨仍有清楚边界。
- 档案一段只有一份可直接编辑文字及整段回听、收藏。短VAD片段仍是底层独立录音，版本、删除和关联不变；详细版本/原音由次级菜单访问。
- 长历史按24段分页，每段读取最多64个原录音文字；超长段有同段前文/后文导航，整段回听、收藏和复制涵盖全部成员。
- 回听顺序播放每份现存原音；缺失/删除/损坏文件不阻止其余可用原音，也不伪称完整。暂停或取消不会重新启动录音。

## 数据兼容

SQLite主schema继续为6，新增独立段落metadata表。录音、原音块、原文字修订不合并或改写；旧应用可以回退读取。段落边界是否被明确删除使用独立字段记录，普通档案改字不改变段界。模型、ASR设置与识别运行库保持原值。

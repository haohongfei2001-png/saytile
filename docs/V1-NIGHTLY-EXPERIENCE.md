# V1 夜间个人体验候选

本轮衔接 PR #18 内置输入修复与 PR #17 整合工程。现有开盖检测、PCM 单独落盘、单一 ASR 文字流与 v6 时间轴继续沿用。所有内容测试使用隔离档案和合成或已许可的公开人声。

## 普通启动与资料

个人安装使用正式 ID `app.saytile.mac` 和经签名封装的 `SaytilePersonalExperience` 标记。普通启动沿用构建 261 的个人目录 `Saytile Personal`、偏好域 `app.saytile.mac.personal` 和既有个人 BYOK、云账户钥匙串服务。只有用户明确选择并授权云识别后才使用相应的通路。保留本机原有正式安装路径。个人包的登录项与正式自动更新均关闭。Finder、菜单栏与悬浮入口使用用户确认的紫色 tile 字形。展开和重新打开输入板均不主动收音。

显式诊断启动使用独立目录、临时偏好域；正式、个人及历史预览目录均在打开 SQLite 前排除。SQLite 版本维持 v6。设备内识别、下载模型与上传授权相互独立。

## 已复现

- 系统继续报告内置麦克风硬件合盖。上一轮合盖停采的修复可复用。用户现场讲话及其主观准确率仍待实际使用。
- 收音重试成功后曾显示上一轮错误；失效设备数字 ID 会丢失固定麦克风。
- 分隔 123 秒的两个时间组触发“插入当前文字”时，旧版本同时选中了两组。暂停时未变化的模型数据仍反复刷新视图。
- Qwen 已将一个公开普通话长句的句首更正，但窗口增长被旧的 24 字符限制阻止。同尺寸的损坏模型在重启后会暂时显示可用，下载退回错误完整响应时还会丢失既有断点。
- 在本机生产下载器单独实测 Qwen 的 712,777,119 字节资源。暂停、恢复、校验、进程重开与临时删除均通过。单次完整下载约 175 秒，使用配置中固定的上游版本。

## 已修复与回归

同一工作树的 AppModel 有 120 项断言通过。固定设备断开仍保留 UID，系统默认只接受显式选择。收音状态恢复后会清除旧设备错误，同时保留独立的存储提醒。暂停期间不再反复发布相同值。

右键插入在点击时读出最新时间组的不可变文字版本，可跨越当前页。档案中明确定位的记录只复用该段。失去原始绑定时余下投递立即停止。用 116 条旧段、跨组间隔、重开、延迟修订及尚未绘制的文字验证了边界。

真实 Qwen worker 产生的中文候选中，修正后的句首连续出现。两次一致并且原有后续文字对齐时，预览可以继续增长；未确定的修订仍不能直接外派。该样本的输入音频时钟更新间隔从 5.0 秒降至 1.6 秒，中英混说对照维持 1.6 秒。[逐帧回放](../evidence/nightly/qwen-worker-frames.json) · [原签名窗口记录](../evidence/nightly/qwen-window-baseline.json)

下载摘要校验在后台执行。错误完整响应保留续传断点，损坏和暂停的本地文件可见且可删除。相关专项 12 项通过。[下载收据](../evidence/nightly/download.json)

新旧签名包安装和回退使用隔离资料。个人包在磁盘映像中也使用独立的应用文件名。最终签名包、同源码全量 CI、实际原生窗口、外部输入和环境阻塞结果列在本 Draft PR 的交付收据。

构建 268 的首轮签名验证覆盖实际窗口、12,000 条时间轴记录、Sparkle 坏包拒绝和两次旧版本迁移。本机 422 项测试通过，Xcode 26.6 的 Swift 6.3.3 编译器在将实例方法适配为登录项的布尔写入闭包时中止。改用显式闭包保留同一调用和断言；输入设备选择器现在提供明确的原生辅助功能名称。

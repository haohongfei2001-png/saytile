# V1 夜间个人体验候选

本轮衔接 PR #18 内置输入修复与 PR #17 整合工程。现有开盖检测、PCM 单独落盘、单一 ASR 文字流与 v6 时间轴继续沿用。所有内容测试使用隔离档案和合成或已许可的公开人声。

## 普通启动与资料

个人安装使用正式 ID `app.saytile.mac` 和经签名封装的 `SaytilePersonalExperience` 标记。普通启动沿用构建 261 的个人目录 `Saytile Personal`、偏好域 `app.saytile.mac.personal` 和既有个人 BYOK、云账户钥匙串服务。只有用户明确选择并授权云识别后才使用相应的通路。保留本机原有正式安装路径。个人包的登录项与正式自动更新均关闭。Finder、菜单栏与悬浮入口使用用户确认的紫色 tile 字形。展开和重新打开输入板均不主动收音。

显式诊断启动使用独立目录、临时偏好域；正式、个人及历史预览目录均在打开 SQLite 前排除。SQLite 版本维持 v6。设备内识别、下载模型与上传授权相互独立。

## 已复现

- 系统继续报告内置麦克风硬件合盖。上一轮合盖停采的修复可复用。用户现场讲话及其主观准确率仍待实际使用。
- 收音重试成功后曾显示上一轮错误；失效设备数字 ID 会丢失固定麦克风。
- 分隔 123 秒的两个时间组触发“插入当前文字”时，旧版本同时选中了两组。暂停时未变化的模型数据仍反复刷新视图。
- Qwen 已将一个公开普通话长句的句首更正，但窗口增长被旧的 24 字符限制阻止。同尺寸的损坏模型在重启后会暂时显示可用，下载退回错误完整响应时还会丢失既有断点。
- 在本机生产下载器单独实测 Qwen 的 712,777,119 字节资源。暂停、恢复、校验、进程重开与临时删除均通过。单次完整下载约 175 秒，使用配置中固定的上游版本。

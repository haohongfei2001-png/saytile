# RC2 首次连接与离线使用

当前候选使用 Qwen Audio3.1 Message、AssemblyAI Universal3.6Pro 与唯一 GPT-6 Astra 融合核心。无需 API Key 也可使用已安装 Apple 识别资源、原音保存、档案、编辑和复制。当前真实云端状态为 `LIVE_CONNECTION_PENDING`，不是 `PRODUCTION_READY`。

## 用户以后启用云端时

1. 打开 Saytile 原生设置中的识别设置。分别在三个安全输入框保存 API Key；Qwen 选择账户对应地区，并填写 Workspace。密钥进入 Saytile 专用 Keychain，不进入配置文件或日志。
2. 对三项服务分别允许必要的音频或候选文字处理。阅读内置连接检查的范围及费用说明，勾选本次检查授权后开始检查。没有单独授权，不调用收费模型。
3. 等待各服务状态和完整检查结果。账户接受、协议可用及合成语音完成分别呈现；只有三项服务与正式融合链路完整通过才自动应用云端。部分失败仍保留本机功能，界面解释安全错误类别。可取消检查，已发生的服务商费用无法撤销。

检查只使用随 App 分发的 6.272 秒中英合成样本。两个 ASR 收到相同音频，GPT 只接收候选文字。单次联网阶段最多 90 秒、6 次实际 GPT 请求，每次最多 4096 输出 Token；重连和 HTTP 回退共享额度。这是请求范围上限，不能保证最终账单金额。详见[范围与预算](../evidence/no-api-product/CONNECTION-CHECK.md)。

首次连接不上传历史原音。每段新录音按当时授权保存目的服务、地区、Workspace 和不含密钥的凭据身份。旧本地录音继续本机恢复，更换服务或密钥也不会自动扩大旧档案权限。需要云端重新处理某段旧音频时，在该档案选择“用云端重新识别”，只授权所选录音。只删除原音仍保留文字及修改稿。

不用终端、修改 JSON、导出配置或联系开发者才能接通。这里描述的是以后用户主动启用的路径；本轮没有索取密钥，也不要求用户参与开发测试。

## 验证边界与旧工具

本机 HTTP/WS 模拟器使用正式网络客户端，但不是实际服务商连接。原生向导的成功/失败/取消交互使用明确标注的测试结果，不证明真实账户或识别质量。即使真实连接检查通过，也不自动升级为 `QUALITY_VERIFIED`。

仓库中的 `--connection-setup` 和 `open-rc2-connection-setup.sh` 保留为隔离工程工具；空目录、绝对路径、禁止生产资料树、非秘密配置导出等防护仍适用。它们不是消费者必须经过的流程，旧五服务说明已被本页三服务流程取代。

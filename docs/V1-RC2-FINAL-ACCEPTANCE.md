# RC2 最终集中验收条件

当前尚未满足进入条件，不请用户执行下面的体验验收。先按一次性授权清单准备核心五服务，由工程方完成公共真人样本联调：两个专家同音频、真实候选融合、确实听取原音的复核、定稿版本、稳定文字输入、失败留档及数字/否定/术语保护。未触发的步骤不能标成功。工程问题全部由工程方复现、修复和回归。

进入条件还包括：当前 PR 审查无已知 P0/P1、适用的自动/异常/原生验证通过、干净候选安装升级证据齐全、剩余硬件/浏览器/签名限制明确披露。通过后才安排一次集中体验判断：

1. 本人允许所需麦克风/语音/辅助功能权限；普通复制不需要辅助功能。不改变系统安全策略，不要求绕过公证限制。
2. 在一次自然讲话中判断中文、英文混说、停顿接续和确认等待是否可接受；检视数字、否定和术语。工程方负责收集既有诊断，不要求另录音或提供日志。
3. 在自建空白测试草稿中判断连续输入、复制和历史复用是否顺畅；不打开私人草稿，不自动发送。

物理设备拔插/锁屏睡眠、多显示器与长期功耗不能仅靠上述三项主观判断补成已验证。工程方应在允许的独立设备环境补实机证据；没有该环境时明确保留限制，由用户集中决定是否接受。当前个人包为 ad-hoc 签名，未 Developer ID 公证。

# Saytile 0.21（564）候选安装

当前为发行验收候选，未公开发布。公证与 Gatekeeper 结果以对应 DMG 的机器收据为准。未通过时不要关闭 Gatekeeper、删除 quarantine 或按正式发行包推广。

当前安装的 0.20（533）保持不变。本轮只在隔离目录运行候选和合成资料。日常资料、录音、设置、Keychain 和模型缓存均不参与破坏性测试。

后续明确选择升级时：先退出 Saytile，将原 App 与完整资料目录一并备份（包括 SQLite、WAL、Audio 和设置），再将 DMG 中唯一的 Saytile.app 放到原安装位置。候选保持既有 Bundle ID、Keychain 服务名和资料路径；不用新建产品、账户或搬动模型缓存。版本号在“语音档案与设置 → 关于”查看。

需要回退时退出候选，恢复旧 App。本轮必须先在合成目录通过 533→564→533 的资料回归；如跨越不兼容的数据格式，应同时恢复升级前的完整资料备份，不把旧 SQLite 覆盖在新录音目录上。备份在确认正常使用前保留。

开发隔离启动语法：`Saytile.app/Contents/MacOS/Saytile --data-directory /绝对路径/全新测试目录 --smoke-test`。它不验证实际麦克风，也不等于日常启动验收。真实麦克风仍遵守合盖暂不测试的决定。

官网和应用内更新只有在发行裁决放行后才指向新包。本候选不自动发布，也不自动覆盖现用 App。

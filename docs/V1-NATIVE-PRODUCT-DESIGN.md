# Saytile V1 原生界面候选

基线为 PR #18 的 `edef1c66faeaa2351ff6fd3b687823eb8c10f689`。对照 build 269 的原生输入板、设置和档案，设置首屏把服务、模型与账户偏好并列，输入设备被推到屏外。设置与档案仍在使用三竖条图案。档案最窄带详情要求 1040 pt，长文在列表重复展开。浮板只保存了进程内的位置。空输入板没有说明第一次如何开启，也没有区分首次成功和第一次启动。

| 窗口 | 具体决定 |
| --- | --- |
| 输入板 | 沿用原图的 344 × 234 pt 内容和 408 × 298 pt 外框。仅首次空白处提示右侧开始和左侧复制。正文出现后结束引导，收音始终由用户启动。按显示器记住最后主动拖动或调整大小的位置。 |
| 设置 | 将声音与服务、本地模型、输入与快捷键、原音存储、关于分开。宽窗侧栏，窄窗用原生选择控件。账户和密钥仅在对应服务显示。使用批准的 tile 位图。 |
| 档案 | 列表以日期与文本为主，选中的一段在详情中编辑。减少重复的卡片、口号和固定高度；窄窗给详情完整阅读宽度。保留原音、历史版本、搜索草稿和只删原音契约。 |
| 材质和反馈 | 主板保持原有中性玻璃、28 pt 圆角、19.5/26 pt 正文与两枚按钮。次级窗口跟随系统明暗，以系统文本色、分隔线、紫色强调和标准表单控件组织层级。点击图形保留辅助标签，选中状态也可通过形状和文字识别。 |

使用独立体验目录保存新候选的资料、偏好、位置和钥匙串。审核图使用隔离资料。授权、硬件、网络和审美分别按实际观察记载。

文字区域的首次提示沿用正文 19.5 pt，说明 12 pt；权限拒绝时仍是同一枚语音按钮，直接打开系统麦克风权限页。完成判定为非空文字进入时间轴，而不是创建空录音或成功申请权限。正常收音不会自动打开设置。侧窗标题、表单、档案分别采用标题、系统正文和 callout/caption；侧栏 164 pt，640 pt 以下改用系统选择器；档案不足 920 pt 时只显示正在阅读的详情。菜单项使用系统控件；按 Esc 关闭详情、⌘F 搜索、⌘S 保存。主板使用系统减少透明度，声形遵循减少动态效果且不虚构声量。窗口状态与错误同步发布；模型文件占用由磁盘更新，确认删除前说明保留文字和原音。

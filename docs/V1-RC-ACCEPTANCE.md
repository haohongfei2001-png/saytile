## 工程证据

| 方面 | 已实际执行 | 范围与限制 |
|---|---|---|
| 原生逻辑 | 122项完整套件、21项生产AppModel | 合成资料/可注入系统边界 |
| 原生界面 | 9个实际窗口视图、5次真实AXPress | 透明非激活窗口；没有抢前台；不是HTML原型 |
| 输入 | 原生NSTextView生产协调器+账本+AX，WebKit变化拒绝，headless DOM | 完整用户前台路由、浏览器实际插入尚未冒称通过；后台WebKit写入未确认时不重发 |
| 原音与恢复 | 真实SIGKILL、WAL、内核写入限制、升级、删除保文、播放器静音 | 不等同整机突然断电 |
| 识别 | 8条两声音实时中文TTS、两个Apple引擎对照 | 有错字；不等同真人/噪声/口音质量。首字约1.2秒；完成延迟口径见音频文档 |
| 长稳/资源 | 30分钟真实墙钟合成管线零drop；5分钟打包App待命；10万档案规模 | 非72小时、非物理麦克风；未测整机功耗；证据中各自SHA准确披露 |
| 生命周期 | 锁/会话/睡眠/权限状态门控、稳定设备UID、关停回归 | 事件注入和代码路径验证；未擅自物理锁屏、睡眠、拔设备或改TCC |
| 安装升级 | 最终DMG签名、Beta→RC迁移、3次重启、重复实例拒绝、强制退出恢复；6组通过 | 只使用独立目录，不读取正式个人档案；实际安装后启动亦通过 |

锁屏桥使用macOS通知与会话快照交叉检查，其中锁状态字段属于兼容接口，无法据此承诺未来所有系统版本。独立产品取舍材料见 `RC-PRODUCT-REVIEW.md`。泛网页中全部AX语义完全相同的隐藏路由不属于已证明支持范围；不能把这一边界写成“用户已接受”。

## 仅在你决定开始验收时

一次完成系统打开确认、麦克风授权；需要插入时才授予辅助功能。复制、档案和编辑无需辅助功能。个人ad-hoc包未Developer ID公证，不能关闭系统安全策略来绕过。

之后只需两项具有个人判断价值的体验：

1. 用自己的正常普通话说约一分钟，包含停顿、否定和数字，判断修正量、跟随速度与回听质量是否满足个人使用。
2. 在自己常用应用的独立空草稿中体验连续输入与切换目标后的停止，判断与该应用的实际兼容性。

不要求提交私人录音、提供日志、做故障注入或替工程反复寻找基础问题。现在无需执行以上项目。

## 发布判断

RC 是供后续完整验收的工程候选，不是正式成熟版。自动/隔离适用测试与原生界面已通过，无新增可复现已知 P0/P1；但完整前台浏览器、物理生命周期及重大产品取舍仍有未完成或未接受的边界，因此**尚不宣称用户列出的全部真人验收准入条件已满足，也不要求现在开始真人验收**。未验证内容不会被替换成 CI_PASS。

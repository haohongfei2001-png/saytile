# Saytile V1 Release Candidate 1

要求：Apple Silicon Mac，macOS 26 或更高。

当前无需为工程推进进行临时测试。下面步骤用于你决定正式试用时；最终验收清单见 `V1-RC-ACCEPTANCE.md`。

## 安装与首次使用

1. 打开 DMG，把 Saytile 拖入 Applications，然后打开。
2. 点击菜单栏波形图标；在输入板点击“开启自由记录”。首次系统提示时允许麦克风。中文系统资源会在后台准备，声音独立保存，不因识别资源尚未就绪而丢失。
3. 自然讲话即可自动分段；可以停顿再接着说。输入板关闭后仍持续收音；菜单栏右键或输入板底部可以暂停。
4. ⌥ 空格展开/收起输入板。如果快捷键被占用，使用菜单栏。

## 把文字放到其他应用

复制不需要辅助功能授权。要直接插入，在系统设置 → 隐私与安全性 → 辅助功能中允许 Saytile。

把光标放在目标草稿，使用快捷键打开输入板，选择直接输入并绑定当前草稿。只会追加之后新讲话的稳定文字。更换应用、页面或光标后需重新绑定；未确认投递不会自动重试。Saytile 不会敲回车或发送消息。较早段在后文已经输入后才识别出的文字会留在输入板，显示迟到状态，供明确取用，避免打乱草稿顺序。密码框、终端、有选区或不能确认页面身份的输入框请使用复制。

网页必须提供可辨识的页面上下文与变化通知；能力不足或页面结构超出安全检查范围时，连续输入不可用，仍可复制或显式单次插入。并不承诺所有网页和编辑器都支持连续输入。

## 历史与存储

语音档案支持搜索、修改、历史版本、回听、重新识别、收藏。仅删除原音会保留文字与全部修改稿；删除整条记录会同时删除文字与原音。

原音默认保留到手动删除，10 GB 是提醒阈值。设置中的清理会保护未识别/失败、收藏、正在录制或使用中的原音。实际资料在 `~/Library/Application Support/Saytile`，升级时请保留此目录。请先退出旧版再替换 App；不要让两份 App 同时使用同一个资料库。RC 会原子升级资料结构，旧 Beta 不应直接打开已升级资料库。

## 个人测试签名

当前包为 ad-hoc 签名，未经过 Apple Developer ID 公证。首次下载可能被 macOS 提示未验证开发者。请核对来源为正式 Saytile 仓库；如果系统允许，可在“隐私与安全性”中对这一次打开进行确认。不要关闭 Gatekeeper、不要修改系统安全策略。若系统不允许打开，可以在当前 Mac 从正式源码运行 `scripts/build-app.sh` 构建本机包。

升级后系统可能要求重新确认辅助功能；这属于个人测试签名限制。项目没有购买开发者计划或变更任何付费方案。

实际验证边界、已知问题及需要真人完成的事项分别见 `V1-TEST-RESULTS.md` 和 `V1-USER-ACTIONS.md`。不把合成语音或模拟输入测试等同真人/所有应用验收。

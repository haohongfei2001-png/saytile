# Saytile V1 RC2 工程候选安装说明

当前内测只安装一个 `Saytile.app`（0.6），应用标识为 `app.saytile.mac`。更新时退出已运行的应用并替换同一路径的程序包；保留原有用户资料和授权。以下记录针对历史候选，不是当前安装步骤。

要求：Apple Silicon Mac，macOS 26 或更高。

本包为 `1.0.0-rc.2-no-api.10`，真实云端联调尚未完成。**当前不要覆盖已安装的 RC1，也不需要用户安装或测试。** 工程包采用 Apple Developer ID Application 签名、Hardened Runtime 和可信时间戳，公证尚待发行方提供授权的 Apple notarytool 配置。普通网上分发需由发行方完成签名与公证，不改变系统策略。工程验证在临时位置和合成数据库内进行；包内 App 不是已通过最终验收的正式 RC2。

无密钥时使用本机 Apple 中文识别。未来接通云端直接在 Saytile 的设置 → AI 识别 → 连接识别服务中完成：选择讲话语言并保存两项密钥：该语言的 ASR 与 OpenAI。中文用 Qwen 时另填地域及 Workspace。分别授权处理，再勾选内置合成语音检查的上传与费用授权并点击“授权并连接”。检查使用应用自带的 6.3 秒合成语音，不打开麦克风、不上传历史内容。所选 ASR 接收和 GPT 定稿均通过后自动启用；失败会显示各服务的具体原因，本机功能仍可使用。无需运行脚本或编辑配置文件。

检查的联网阶段最长90秒、最多6次AI请求、每次最多4096输出Token，允许取消；真实账单由各服务商账户承担。检查只证明连接与合成语音流程，真实讲话准确率仍待评估。

## 未来获准升级及回退

只有真实云端与产品验收条件满足后，才按以下步骤替换 RC1：

1. 完全退出所有 Saytile 进程。先将 `~/Library/Application Support/Saytile` **整个目录**复制到独立备份位置，保留 SQLite、WAL/SHM（如有）及 Audio；同时保留原 RC1 App/DMG。不要只复制数据库文件，也不要在 App 运行时复制。
2. 确认备份后再替换 App。RC2 会将 schema 2/3/4 原子迁移至 schema 5，保留原音、文字版本、修改稿及投递状态。正常打开不会自动恢复麦克风或旧输入目标。旧录音没有云端恢复授权，迁移不会补授；以前仅本机处理的原音继续本机恢复。
3. **RC1 及旧 schema 4 候选不能原地打开 schema 5。** 若决定回退，先退出 RC2，将升级后的完整目录另存；恢复升级前的完整目录副本并使用 RC1 App。不要将新旧目录合并，不要让旧版强行修改新库。RC2 期间新增内容仍保留在另存的升级后目录，不能承诺自动回流到旧版。

以下为完成上述条件后的常规使用步骤；最终门槛见 `V1-RC2-FINAL-ACCEPTANCE.md`，不是当前验收邀请。

## 安装与首次使用

1. 打开 DMG，把 Saytile 拖入 Applications，然后打开。
2. 打开 Saytile 后，语音板默认可见。若上次已收起，单击菜单栏图标并选「显示语音板」。点击板上带播放三角的语音键开始。首次系统提示时允许麦克风。中文系统资源会在后台准备，声音独立保存，不因识别资源尚未就绪而丢失。
3. 圆点表示待命，讲话时才出现随音量变化的波形；一段讲话结束即回到圆点，后台仍可完善文字。可以自然停顿，再接着说。输入板关闭后仍持续收音；要暂停或继续，点击语音板右侧的语音键；如果板已收起，先在菜单栏选择「显示语音板」。
4. ⌥ 空格展开/收起输入板。如果快捷键被占用，使用菜单栏。设置中可开启桌面小入口；它只展开同一个输入板，不改变收音状态。

## 把文字放到其他应用

左下角复制按钮在有选区时复制所选文字，否则复制整份当前文字。右键菜单还可以编辑最近一段、回到最新、打开档案或设置。复制不需要辅助功能授权。要直接插入，在系统设置 → 隐私与安全性 → 辅助功能中允许 Saytile。

把光标放在目标草稿，使用快捷键打开输入板，右键点击复制按钮或正文，在菜单中选择“直接输入”，再选择“绑定当前草稿”。只会插入之后新讲话的稳定文字；若稍后确认需要纠错，只修正仍明确由 Saytile 拥有且未被手动修改的局部范围。不能安全确认时，修订保留在输入板供复制。更换应用、页面或光标后需重新绑定；未确认投递不会自动重试。Saytile 不会敲回车或发送消息。较早段在后文已经输入后才识别出的文字会留在输入板，显示迟到状态，供明确取用，避免打乱草稿顺序。密码框、终端、有选区或不能确认页面身份的输入框请使用复制。

网页必须提供可辨识的页面上下文与变化通知；能力不足或页面结构超出安全检查范围时，连续输入不可用，仍可复制或显式单次插入。并不承诺所有网页和编辑器都支持连续输入。

## 历史与存储

语音档案支持搜索、修改、历史版本、回听、重新识别、收藏。仅删除原音会保留文字与全部修改稿；删除整条记录会同时删除文字与原音。

原音默认保留到手动删除，10 GB 是提醒阈值。设置中的清理会保护未识别/失败、收藏、正在录制或使用中的原音。实际资料在 `~/Library/Application Support/Saytile`，升级时请保留此目录。请先退出旧版再替换 App；不要让两份 App 同时使用同一个资料库。RC2 会原子升级资料结构；RC1 和旧 Beta 均不应直接打开升级后的资料库，按上面的完整副本流程回退。

## 卸载

退出 Saytile 后可移除候选 App；卸载 App 不自动删除语音档案。需要删除 Key 时请先在设置中逐项移除。不要因为卸载候选而删除 RC1 或其资料目录。

## 个人测试签名

当前包及 App 已经 Developer ID 签名。普通 Gatekeeper 返回 Unnotarized Developer ID。公开分发需要发行方完成 Apple 公证并验证票据。保留 RC1 与完整备份。

升级后系统可能要求重新确认辅助功能；这取决于 macOS 对签名身份和安装副本的识别。项目没有购买开发者计划或变更任何付费方案。

实际验证边界、已知问题及需要真人完成的事项分别见 `V1-TEST-RESULTS.md` 和 `V1-USER-ACTIONS.md`。不把合成语音或模拟输入测试等同真人/所有应用验收。

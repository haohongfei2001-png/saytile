# Saytile 竞争优势与差距裁决

日期：2026-11-07

## 1. 独立判断

Saytile 不应以“模型数量更多”作为差异化。当前 PR #4 的复杂度明显高于多数竞品公开披露的模型编排，但这不是竞争优势的证明。用户购买的是稳定、准确、随时可复用的表达，而不是看见五家模型并行。

Saytile 有机会形成的产品差异是：**Always-on、原音永久可恢复、表达历史可搜索复用、自由记录与直接输入双工作流、离线连续性、证据可追溯的文本修订**。这些能力必须做成完整体验，否则“语音工作台”会被用户理解为比按键说话更重的录音管理软件。

## 2. 与竞品的结构差距

| 维度 | 头部竞品已公开能力 | Saytile 当前基础 | 差距/决策 |
|---|---|---|---|
| 使用摩擦 | Aqua/Wispr/Willow 多以快捷键触发并快速插入 | Saytile 常驻自由记录，不逐句启动 | 常驻是差异，但首次授权、状态理解、误录控制必须优秀 |
| 实时预览 | Aqua Realtime、Apple volatile、云端流式 | 多路 ModelRun / 候选 / 融合 | 工程链路复杂；实际首显和确认时延尚未实测 |
| 识别质量 | Avalon 领域训练、Soniox v6 混说、云端专有模型 | Qwen/Assembly/Meta/Soniox 等候选 | 未有真实云端收益证明；不能宣称领先 |
| 离线 | Apple、Superwhisper、Willow Mac/iOS | Apple 路径与云端路径曾互斥 | 必须统一到 Capture/Journal 之后，云断开不停止采集 |
| 原音恢复 | Wispr/Willow 提供失败重试；Superwhisper 本地可选 | Saytile 独立 PCMJournal、SQLite 与版本账本 | 有潜在优势；需要验证长期运行、磁盘故障与压缩 |
| 上下文 | Wispr 丰富 app/selection/screen；Aqua 单次屏幕词提取 | PR #4 有话题/术语提示，缺少系统化上下文 | V1 做最小权限上下文，V2 才研究屏幕 OCR |
| 个人词汇 | Aqua Dictionary、Willow 自动词典 | 用户纠错保护已实现，长期学习未实现 | 先记录明确纠错，不自动猜测偏好 |
| 表达修正 | Wispr Backtrack、Undo AI edit | 具备候选修订与用户稿保护 | 增加 raw/formatted/user-edited 明确分层 |
| 模式组合 | Superwhisper/VoiceInk 的 Mode | 快速/最高质量 | 策略应独立于模型配置，避免复杂配置成为用户负担 |
| 长期历史 | Saytile 的核心定位 | 音文独立保存、搜索、回放 | 形成差异的关键；搜索和复用体验要达到日常可用 |
| 输入可靠性 | 竞品通常 paste at cursor；Auto Send 由产品决定 | 稳定 UTF-16 ledger、目标绑定与不自动发送 | Saytile 应坚持不自动发送、无重复派发、无全文覆盖 |

## 3. 推荐竞争定位

不是“最准确 ASR”，除非有可复现数据支持。

推荐表述：个人语音输入与表达工作台——始终待命，原音和文字独立留存，讲话可连续形成可搜索、可修订、可复用的内容；联网时使用授权的高质量识别，离线时保留录音和可用的本地转写。

三个可验证产品承诺：
1. 网络断开、任一模型失败，不丢失已确认落盘的原音。
2. 识别错误可以从原音重试，所有文本版本和用户修改可追溯。
3. 用户明确启用直接输入后，只追加新确认的文字，不发送、不覆盖、不重复插入。

## 4. Saytile 不应做的事情

- 不把“本地和云端始终并行”作为技术信条。
- 不为展示技术实力让所有 ASR 每次都识别完整音频。
- 不把 GPT 文本推理描述成声学复听。
- 不用模型 confidence 跨厂商比较。
- 不用 LLM 把 ASR 错误改成听起来合理的句子。
- 不在 V1 默认截屏或读取聊天内容。
- 不把用户每次纠错自动写成个人词典；只有明确确认的纠错可成为后续学习数据。
- 不用自动输入替代用户的发送决策。

## 5. 需要证明的壁垒

壁垒不是 API 接入。真正可能累积的资产：
- 个人确认过的词汇与纠错事件（用户可查看、编辑、删除）。
- 长期音频与文字版本之间的可追溯关联。
- 对常驻录音的资源管理、恢复、功耗与低打扰体验。
- 在相同硬件和语言场景下，持续测量识别质量/延迟/修改率形成的调度策略。
- 与 Mac 原生输入、权限和应用焦点的可靠集成。

这些都需要产品留存与用户价值证明，不是当前已形成的技术护城河。

# Saytile 最高质量中英文并行 ASR

**本轮正式替代 PR #4 旧版的单 Soniox 裁决，并已进入 Swift 工程实现。**

首选架构是中文专家与英文专家对同一音频实时并行，AI 根据真实候选、时间和原音证据融合；只有统一发布器能生成正式文字与外部输入前缀。成本和模型数量不作为主要约束，最高质量是默认确认策略。
